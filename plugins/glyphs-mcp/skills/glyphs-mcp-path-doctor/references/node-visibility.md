# Missing nodes or handles

Check View settings, the Select tool, the exact foreground layer and locks first.
A previously investigated invisible-node incident was explained by a View setting.
A separate reported case implicated a Pen-point association on a zero-length
closing LINE. Neither establishes a general Glyphs root cause.

## Qualify a node-preserving workaround

Reuse a valid document binding and obtain fresh current-font evidence when the
request depends on the current font. Capture complete live state, including
unsaved edits. Report document/workflow IDs are historical: never replay scripts
or restore an earlier capture over later manual edits.

Use existing disposable glyphs/layers and fixed targets. Under identical view
conditions compare unchanged, node-0-association-cleared and final-endpoint-
association-cleared variants. Grammar-invalid deletions cannot qualify a repair.
Require the exact closed zero-length LINE pattern and one redundant node-0
control at local t=1 matching the real incoming endpoint's complete semantics,
including explicit/inherited storage. Preflight every corresponding master and
relevant special interpolation layer. Conflicts, locks, unsupported references,
uncertain correspondence or any failing layer hold the coordinated proposal.

Compare fresh detached native expansions and exact coordinates/types/flags.
Preserve every centerline node, real-segment control, path attribute, default and
unrelated datum. Check native outline compatibility and profile correspondence
independently. Validate native intermediate instances before making variable-
preservation claims; otherwise identify that coverage as unqualified.

## Apply and review

Only an explicit repair request authorizes application. Use the existing
[native-script workflow](https://github.com/thierryc/Glyphs-mcp/blob/main/skills/glyphs/references/python-scripts.md) with fresh
geometry/attribute/profile guards. Archive the original association locally and
clear only the qualified redundant association. This playbook adds no tool,
automatic sweep or reusable repair helper.

This is a visibility workaround: every node and the seam remain. The remaining
seam diagnostic is expected and must not trigger normalization. Separately
requested [seam normalization](repair.md) changes topology. Idempotence here means
that no further association-clearing change is required.

Report visibility, selection and dragging separately; test dragging only on
disposables. Use Changes Against Reference for visual comparison where available;
matching ink alone proves neither interaction recovery nor profile preservation.

Script recovery is whole-font Restore before run, not typed selective Undo and
not an atomic-execution guarantee. Never automatically restore over later edits.
A targeted reversal needs fresh guards. Save/reopen is a separate qualification.
If sidebar alerts occur, stop adding probe glyphs; do not manipulate filters or
repair sidebar behavior in this workflow. Hand off partial execution or a sidebar
incident explicitly. Keep captures, associations and private identifiers local.
Public bug claims require original generic fixtures and independent evidence.
