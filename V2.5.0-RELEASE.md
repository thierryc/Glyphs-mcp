# Glyphs MCP 2.5.0 — release qualification

Release identity: **2.5.0/build 73**, stable channel, tag `v2.5.0`.
Developer ID signing, Apple notarization and final artifact qualification have
passed. Publication and update-feed promotion are pending; the public baseline
remains 2.4.0 until the verified archives are published.

## Changes

- Add read-only live Path Doctor diagnostics and an explicitly requested,
  qualified closed-seam repair through existing preparation, outline operations,
  state guards, selective recovery and native Undo. Preserve real geometry,
  traversal order, profiles, attributes and inherited defaults.
- Add correspondence-first Pen-point cleanup guidance with cumulative measured
  error budgets across masters and intermediate instances. This is a guided
  workflow, not an automatic redistribution command.
- Make the self-contained, licensed Path Doctor skill discoverable and
  downloadable by existing apps; prefer the canonical included skill in 2.5.0.
- Present the MCP icon, website and readable workflow labels to Codex. Reuse
  matching plugin connections and preserve custom, disabled, conflicting or
  freshly edited configuration.
- Show measured or indeterminate progress, finishing phases and partial failures
  in compact accessible workflow cards without changing execution or recovery.
- Keep server status in the top-right toolbar across views, including with the
  sidebar hidden. Clicking it opens Setup. Hide its duplicate system background
  on macOS 26 and later, retaining the older-system fallback.

The public catalog has **22 tools and 13 managed skills**. Bridge and sidecar
versions are coordinated at 2.5.0; interface revision 1 and bridge protocol 1
are unchanged. Glyphs 3 remains the separate pinned 1.11.0 release.

## Qualification

The initial build-72 source preflight passed **3,328 Python tests** (three expected skips),
**325 desktop tests**, documentation, managed-skill/package checks,
deterministic payload builds and startup/HTTP/stdio checks for both private
runtimes. An expanded native regression then exposed a metadata-container
restoration issue. Build 73 fixes it by rebuilding native dictionary/array
containers without changing numbers or Pen-point values. The updated native
qualification runner includes the current incremental Undo-finalization API.
Build 72 remains unpublished.

The exact final signed payload passed eight Path Doctor native check groups,
including metadata readability and exact recovery. A generic two-master,
12-layer fixture passed four qualified repairs, four explicit conflict/lock
holds, independent numeric geometry/profile/default checks, selective recovery,
stale refusal, idempotence and differential native Save/reopen. The existing
nine-master outline regression passed apply, partial-failure rollback,
cancellation, real Undo/Redo, discard, Save/reopen, native removal variants,
selection, hint identity, components, anchors and metadata preservation.
All imported implementation modules were verified inside the signed payload.

Both signed runtimes passed startup/HTTP/stdio checks: 4.290 seconds on arm64
and 9.815 seconds on x86_64 via Rosetta. These startup measurements are separate
from native edit and responsiveness measurements. All 23 feedback tests passed
against the locked runtime SDK without skips. Public aggregate evidence is in
[publication qualification](reports/release-2.5.0-candidate/README.md).

Apple accepted the expanded payload, final universal app and disk image.
Developer ID, hardened runtime, secure timestamps, nested signatures, tickets,
Gatekeeper, component identities, signature-preserving installation copies and
signed update archive/feed checks passed. The final read-only mounted DMG passed
visual review. The complete frozen-source gate and anonymous downloads are
verified by the publication pipeline before feed promotion.

## Acceptance scope and retained limits

Native seam repair is qualified on Glyphs **4.2/build 4202** for foreground
ordinary masters. Other hosts remain diagnostic-only. Conflicting profiles,
locks, references and unsupported structures are held. Fill, smoothness,
intentional open returns, start points and direction are independent findings.
Native Save can reduce arbitrary live-coordinate precision; an exact in-memory
repair does not promise lossless native persistence.

The earlier installed Path Doctor acceptance and private disposable-font work
retain their recorded scope in [Path Doctor qualification](reports/path-doctor-20261029.md).
Invisible nodes were traced to a View setting; the seam is not claimed as the
cause of every editing failure. OpenPlotFont converter changes remain work in
its owning repository.

Codex attribution/progress qualification is recorded in
[Codex integration](docs/codex-feedback.md). Icon placement is host-dependent;
the tested direct-call Codex endpoint does not forward standard MCP progress
notifications. Structured workflow state and optional cards remain available.

The release workflow does not replace the user's installed manager, bridge,
sidecar, open fonts or task records. Native checks use original generic fixtures
in isolated processes. Private fonts, profile measurements, drawings,
screenshots and test copies remain local and are excluded from Git and release
artifacts. Physical Intel hardware and a fresh full GUI updater/VM matrix are
not claimed; Intel runtime checks use Rosetta, and earlier updater evidence
keeps its original version scope.
