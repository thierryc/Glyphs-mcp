title: Skills and optional plugins
---

Skills tell an agent how to use the supported workflows. They do not add tools to the server or grant permission to edit a font.

Opening an existing native font uses `open_document` and the shipped
`glyphs/references/font-opening.md` guidance. It requires a coordinated bridge
and sidecar with `document.open.v1`; it does not require a saved baseline or script.

The source package at `plugins/glyphs-mcp` has **2.7.0** manifests for **Codex**, **Claude Code**, **Cursor**, and **GitHub Copilot CLI**. Setup configures Codex and Claude Code with MCP and managed skills, configures Claude Desktop's MCP entry, and installs the Cursor bundle at `~/.cursor/plugins/local/glyphs-mcp`. GitHub Copilot CLI uses the agent package directly.

The agent plugin is optional for using the twenty-one data/action tools and optional card-display tool; a manual MCP
connection can use the same server catalog. **Install All** nevertheless
includes all four supported Setup connectors by default, even if a host is not
detected. Use the published 2.6.0 package with the stable 2.6.0 runtime and the
local 2.7.0 package with the 2.7.0 candidate.
Configuration patching creates backups, preserves unrelated entries and custom
options, and changes only Glyphs MCP. Cursor update and removal require an
installer-owned bundle whose version and hash still match its receipt; modified
or unowned content becomes a visible conflict. Public marketplace commands
resolve published state; verify that the installed package version matches
your runtime before using its workflow instructions. Use the matching local package when testing unreleased capabilities.

## Included skills

The table describes the **14 managed skills** in the 2.7.0 candidate and stable 2.6.0. Small and Petite Caps joined the bundle in 2.6.0.

| Skill | Use |
| --- | --- |
| `glyphs` | Verify the specific connection when needed; reuse its context and document ID. |
| `glyphs-mcp-spacing` | Prepare and review sampled spacing suggestions. |
| `glyphs-mcp-kerning` | Review explicit collision-kerning pairs. |
| `glyphs-mcp-italic-first-pass` | Prepare a guarded first-pass slant. |
| `glyphs-mcp-small-caps` | Derive small and petite capitals with pilot approval and protected human corrections. |
| `glyphs-mcp-master-compatibility` | Review start-node correspondence; full master compatibility repair is not advertised. |
| `glyphs-mcp-outlines-docs` | Inspect bounded outline information and native documentation. |
| `glyphs-mcp-path-doctor` | Diagnose paths and propose qualified repairs that preserve authored stroke profiles. |
| `glyphs-mcp-development` | Develop reusable scripts or plugins in the workspace. |
| `glyphs-mcp-scripting` | Prepare reviewed scripts for native execution. |
| `glyphs-mcp-opentype-features` | Review and debug native Glyphs 4 feature source, compilation and exported behavior. |
| `glyphs-mcp-hinting` | Inventory hints and compare PostScript, CFF2 or TrueType rendering before scoped repairs. |
| `glyphs-mcp-release` | Prepare and validate repository releases. |
| `glyphs-mcp-maintainer-feedback` | Turn a reproducible issue into useful maintainer evidence. |

Use the general `glyphs` skill when unsure which workflow fits. Workspace development can start without an open font. Live jobs require a ready server/bridge and an explicit scope. Script jobs can run on unsaved or dirty fonts with pre-run memory recovery; other operations retain their advertised baseline requirements.

The v1 guide retains its [marketplace and skill instructions](/docs/getting-started/use-agent-skills). Do not reuse v1 tool calls with the v2 server. See the [migration guide](migrate-from-v1.mdx).

OpenType source work uses `glyphs-mcp-opentype-features` for native Glyphs 4
scripts, compilation diagnostics and exported behavior checks. This skill adds
no additional public tool: native source edits use the existing `python_script` workflow when `script.native.v1` is available.

## Preserved conflicts and retired private skills

Unchanged installer-owned skills refresh automatically. User-edited or unowned
folders remain **preserved-conflict** with their exact path and a repair action.
Review them, then use **Replace preserved skills (backup)** when replacement is
intended. Exact backups and restoration coordinates go in the sibling
`glyphs-mcp-skill-backups` folder outside skill discovery, not beside selectable
`SKILL.md` files. The installer log gives each complete backup path.

Recognized retired private icon-font, LitSquare, color-font, variable-font,
production-audit, Unicode-semantics and export-validation folders are archived
by that action; they are not replaced by newly supported audit tools. Separate
v1 instructions are preserved. The current entry explains bounded reads,
separately scoped native coding, and unsupported specialized tasks.

A skill requiring `get_server_info` and `apiMajor == 2` can be an obsolete
private instruction, not proof that a current lean runtime needs updating.
Check its actual path and connection catalog. The installer does not edit plugin
caches or source worktrees. Refresh the client's skill discovery after changes;
an existing task may retain old instructions. Do not assume hot reload.

## Skills catalog

Open **Skills** below Setup to browse included, curated and reviewed community
workflows. **Companion Plugins** and **AI Agents** open focused pages that share
the same operations and status with the complete Setup overview.

Included means shipped with this app; it is separate from installation status.
Compact text cards show each workflow’s goal and whether it is included, installed
or available. Open **Details** for installation options, instructions, source
and licensing.

- **Default for all projects** installs, updates or removes the copies available
  across projects on this Mac.
- **By agent** manages individual skill copies. When a copy comes with the
  Glyphs MCP plugin for Cursor, **Open AI Agents** takes you to the controls
  for updating or removing the whole plugin.
- **Project copies** shows the folders where this skill is installed locally,
  with update and remove controls for each copy. Use **Install in a project…**
  or **Install in another project…** to add a copy for all compatible local
  agents in the folder you choose. Agents with a Mac-wide copy can use it in
  any project. If you use that copy, remove redundant project copies to avoid
  keeping different versions. An orange warning marks an unavailable folder
  in **My Project** and beside any skill copy previously found there.

There is no global on/off switch: skill discovery belongs to each client and does
not enable or disable the corresponding MCP tools.

Supplemental Codex/Cursor skills share `~/.agents/skills`; existing copies in
`~/.codex/skills` or `~/.cursor/skills` are detected and updated in their actual
location. Claude Code uses `~/.claude/skills`. Project copies live inside the
chosen folder, typically in `.agents/skills` or `.claude/skills`. Changes to
the default and to each project copy are independent.

**Import from GitHub** accepts a public repository URL with separate directory
and optional revision fields. It resolves an immutable commit, lets you choose
from multiple skills and keeps the import personal and unreviewed. Inspect its
instructions, file list, license and dependencies before installation. Private
repository authentication and Gist import are not included in this release.

A circled check shows that the installed files match the available package.
Skills with their own version number show it beside the check. The Git revision
is available under **Advanced**. A **Tested with** note names the agents used
for testing. Compatible agents can still install and manage the skill.
For community skills, **Share feedback on GitHub** lets you report problems or
tell the contributor what worked. **Reinstall** stays available for a matching copy.
**Update** is highlighted when a managed copy differs from the available
package. Locally edited or unverified copies require confirmation and a backup
before replacement or removal. When a copy is linked, the action changes only
the link and preserves its source folder. Find backup paths under **Advanced**.

**Export ZIP** produces a complete skill folder for guided upload to ChatGPT or
Claude where account permissions allow. Export is not installation. Upload and
enable the package in the host and configure its dependencies separately;
uploading instructions alone does not make Glyphs on this Mac accessible to
hosted execution. The app does not execute downloaded scripts or install MCP
connections/dependencies as part of skill installation.

The [contribution repository](https://github.com/thierryc/glyphs-mcp-skills) accepts
skill folders and pinned external GitHub entries through reviewed pull requests.
Its template, submission forms and validator support a first contribution.
Curated entries are selected by maintainers; Community entries are reviewed
submissions. The app includes an offline snapshot and retains its last valid
catalog if a refresh fails. Optional skills remain outside Install All.

## Optional development skills in Setup

Select **Include Glyphs MCP development skills** in Connections to add script/plugin
development and release skills to Codex and Claude Code during setup. The checkbox
starts unchecked and remembers your choice. Existing development skills stay in
place, and local development or release copies do not make connection setup fail.
The development skill is also available in the Skills catalog.
