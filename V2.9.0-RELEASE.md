# Glyphs MCP 2.9.0 / build 96

Stable release for Glyphs 4. [Download the notarized installer](https://github.com/thierryc/Glyphs-mcp/releases/download/v2.9.0/Glyphs-MCP-2.9.0.dmg) · [GitHub release](https://github.com/thierryc/Glyphs-mcp/releases/tag/v2.9.0)

## Changes

After a desktop app update, Glyphs MCP offers a wizard when it finds verified installed components or managed skills that need updating. You can also do the work manually in Setup.

The wizard detects whether Glyphs 4 is open. For plugin changes that require it to close, **Quit Glyphs** uses the app’s usual save prompts. **Save and quit Glyphs** asks Glyphs to save changes in all open fonts as it quits. The installer waits for those processes to exit. Skill-only changes can proceed while Glyphs is open.

New optional items, including catalog skills released with the app, have their own opt-in step. The wizard installs the selected changes from one **Install** button and can retry unfinished work. 2.9.0 ships the same 15 managed skills and catalog entries as 2.8.2.

- The VM showed no native Automation prompt. A simulated permission-denied Apple Event reply exercised the wizard’s recovery. Glyphs stayed open, MCP restarted, and manually quitting Glyphs let installation finish.
