# Glyphs MCP 2.3.1 — published qualification

Published **2.3.1/build 69**, stable channel, signed tag `v2.3.1`.
Prior 2.3.0 assets and signed release tags remain intact.

## Changes

- Present the Glyphs MCP development skill positively in the Codex and Claude
  Code connection cards, with its availability in Skills.
- Add **Include Glyphs MCP development skills** to Connections. It starts
  unchecked, remembers the choice, and includes script/plugin development and
  release skills when setting up Codex or Claude Code.
- Preserve existing development and release skills without marking successful
  connection setup as failed. Opting out leaves their copies and ownership
  receipts intact. Conflicts in other managed font-workflow skills retain their
  existing protection and reporting.
- Translate the new interface copy into English, French and Simplified Chinese.

## Qualification

The complete gate passed **3,155 Python tests** (two skipped), **305 desktop
tests**, documentation, deterministic payloads and skill/package checks.
Apple accepted the expanded payload, final app and disk image. Stapling,
Developer ID signatures, hardened runtime, timestamps, Gatekeeper, component
identities and signed update archive/feed checks passed. Both exact signed
private runtimes passed HTTP/stdio and packaged CLI checks. The final disk image
was visually reviewed before upload. All six GitHub assets passed anonymous
public-download and checksum verification before feed promotion.

The tag points to `f6c312d4`. The first gate stopped at a broken
documentation link before signing or upload; the corrected complete gate passed.
No native font behavior or updater implementation changed. Prior 2.3.0 native
and VM evidence retains its original scope; no new full GUI updater/VM test or
local installation was performed. Intel execution used Rosetta.
