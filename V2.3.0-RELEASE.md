# Glyphs MCP 2.3.0 — release candidate

Source target: **2.3.0/build 68**, stable channel. Published 2.2.0 assets and feeds remain unchanged during preparation.

## Changes

- Compare installed MCP and bundled inspector receipts with the corresponding bundled component versions and identities. Unchanged inspectors remain current; newer, development-linked and unverified installations do not trigger an update reminder.
- Show a one-time “A new version of the MCP server in Glyphs is available.” dialog with a separate plugin-only headline and clear card-by-card instructions after discovery when the main app opens interactively and installed components need updating. Open Setup navigates without starting installation; Later leaves the card indication visible. Defer during quiet login launches, active installations and another dialog. Scope acknowledgement to app version/build and installation location.
- Show Update available and a filled blue primary Update button with its refresh icon and semibold label on affected cards. Keep current-component Update and Uninstall secondary, preserving disabled states and installation safeguards.
- Refresh availability after discovery, manual refresh and installation success/failure/cancellation. Add English, French and Chinese strings.

## Compatibility and scope

Desktop, bridge, sidecar and agent package target 2.3.0. The catalog remains 22 tools; interface revision and bridge protocol remain 1, with eleven managed skills. Glyphs 3 remains pinned to 1.11.0. Inspector versions remain unchanged. Beztrace managed integration targets engine 0.2.1 and companion 0.2.0/build 25, Apple Silicon/macOS 26.6.2 or later, with manual engine selection. Independent or modified installations, shared engines and user settings remain protected. Optional tools remain outside Install All. Diffenator is deferred to a future release and removed from Setup. Its existing comparison protocol remains unchanged, with no runtime distributed in 2.3.0.

No automatic component installation or Glyphs restart is added. Desktop replacement and component migration remain separate. The sidebar-filter alert was not reproduced in the prior 20-run VM experiment; automatic count suppression remains off and mitigation effectiveness is unproven.

## Diffenator deferred

Diffenator is outside the 2.3.0 scope. No Diffenator runtime or release asset is
included, and the Setup card is removed. Historical candidate evidence remains
archived in [the qualification report](reports/diffenator-arm64-2.3.0/README.md);
it is not a distribution approval.

A future maintained fork will replace `youseedee` with an independently written
bundled-Unicode reader. It must pass dependency/license checks, comparison tests,
signing, notarization and supported-macOS qualification before returning to Setup.

## Qualification

The current source candidate passed the complete gate: **3,155 Python tests**, **304 desktop tests**, documentation checks, deterministic payload checks and skill/package consistency checks. Two Python tests were skipped. A disposable re-signing test verified both inspector signatures, different full identities and an identical stable content identity.

The app validated by this gate was unsigned and unnotarized. It is not publishable. Exact signed upgrade/reminder verification in VirtualBuddy and final localized optional-tool Details/keyboard/accessibility review remain pending. Earlier reminder cards were reviewed in English, French and Chinese, light and dark appearance; those results retain their earlier local-candidate scope.

Physical Intel hardware is unavailable; any x86_64 execution is under Rosetta. Previous VM graphics/progress-window, exact macOS 14.0, client-coverage and accessibility/localization limits retain their recorded scope.
