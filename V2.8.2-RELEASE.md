# Glyphs MCP 2.8.2 / build 95

Local release candidate for Glyphs 4.

## What changed

When Glyphs 4 quits, Setup shows **Glyphs 4 has quit**. The expanded health panel labels its most recent memory reading **Last footprint before quit** and retains the sample time. The panel and its copied Markdown report hide editing guidance while Glyphs is closed. If the companion starts with Glyphs already closed and has no sample, it displays **No health sample is available.**

## Live verification

On 19 November 2026, Glyphs 4.2 (4204) ran with zero open fonts. The installed companion with the fix, still labeled 2.8.1 build 94, displayed a final live footprint of **124.2 MB** with Agent guidance visible. After Glyphs quit, the expanded panel showed **Last footprint before quit, 124.2 MB** and omitted Agent guidance. The same value remained visible after the MCP server stopped.

## Compatibility

Desktop build 95 coordinates the 2.8.2 bridge, sidecar and agent packages. The bridge protocol and lean interface are both revision 1. Glyphs 3 continues to use the separate 1.11.0 release.
