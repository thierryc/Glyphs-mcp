title: Glyphs 4 MCP tools
---

The canonical v2 reference is now [The eighteen v2 tools](command-set.mdx). This page remains available for existing repository links.

The tools are `get_status`, `list_documents`, `create_document`, `open_document`, `import_document`,
`activate_document`, `close_document`, `read_entities`, `start_job`,
`compare_fonts`, `get_job`, `apply_job`, `accept_job`, `discard_job`, `save_document`,
`start_edit_workflow`, `get_edit_workflow`, and `respond_edit_workflow`.

Start with the [first session](../tutorial/first-session.mdx) or read the
[complete signatures, selectors and job kinds](command-set.mdx). Application is
save-free; `accept_job` performs verified whole-document persistence after
review, while recovery and native history retain exact values.
