# Glyphs MCP 2.9.0 / build 96

Unpublished release candidate for Glyphs 4.

## Changes

After a desktop app update, Glyphs MCP offers a wizard when it finds verified installed components or managed skills that need updating. You can also do the work manually in Setup.

The wizard detects whether Glyphs 4 is open. For plugin changes that require it to close, **Quit Glyphs** uses the app’s usual save prompts. **Save and quit Glyphs** asks Glyphs to save changes in all open fonts as it quits. The installer waits for those processes to exit. Skill-only changes can proceed while Glyphs is open.

New optional items, including catalog skills released with the app, have their own opt-in step. The wizard installs the selected changes from one **Install** button and can retry unfinished work. The 2.9.0 candidate ships the same 15 managed skills and catalog entries as 2.8.2.

## Compatibility and release checks

Build 96 coordinates the 2.9.0 desktop, bridge, sidecar, and agent packages. The lean interface and bridge protocol retain revision 1. Glyphs 3 retains the separate 1.11.0 release.

The release checks cover the full local gate, the signed 2.8.2 to 2.9.0 upgrade, and the wizard in the signed app with disposable fonts. Test multiple edited fonts, an untitled font, a cancelled save, denied Automation permission, active MCP work, and multiple Glyphs 4 copies before publishing. The published stable feed continues to serve 2.8.2.
