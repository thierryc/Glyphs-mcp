---
title: Start and stop the server
---

Open **Edit → Glyphs MCP Server…** in Glyphs. The command is available even with no font open.

- **Start** connects the native bridge and starts the external MCP server.
- **Stop** stops the server and its Glyphs connection. Stop is refused during an active native write; external preparation is cancelled on shutdown.
- The automatic-start setting controls the external server at the next login.

The bridge is application-wide. Opening another document does not undo a manual Stop, and closing one document does not stop the shared service.

## Ports

The default MCP URL is `http://127.0.0.1:9680/mcp/`. Copy it from the server window into your client. Port **9681** belongs to the private bridge connection and is hidden from the Glyphs interface. The extension panel simply shows **Ready**.

To change the MCP port, edit it in the server window and apply the setting. A running server restarts; a stopped server stays stopped. Invalid, reserved or occupied ports are rejected before shutdown. Update the client URL after a successful change.

Call `get_status` from your connected client to check the sidecar, bridge and worker separately. See [Troubleshooting](troubleshooting.mdx) if only part of the connection is available.

## Before restarting

Finish, accept or discard active work and review the outcome. Use `accept_job`
for an authorized persistence action before restarting. Job IDs belong to the
current server session; restarting is not a way to continue or reconcile an
uncertain operation. Use `get_job` first.
