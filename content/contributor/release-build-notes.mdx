## Discoverable releases

The desktop uses checksum-pinned Sparkle and PierreDiffsSwift packages. Build
receipts verify the Pierre package resource bundle and the exact bundled
`@pierre/diffs` and Shiki JavaScript identities. **Check for Updates** runs on
demand; automatic checking is enabled by default and can be disabled in Settings. Beta 10 uses
`https://raw.githubusercontent.com/thierryc/Glyphs-mcp/lit/v2-beta/appcast.xml`
and archives under its planned `v2.0.0-beta.10` prerelease tag. Stable builds use
their separate stable feed. Sparkle update ordering uses increasing installer
builds, not the marketing-version label. A configured feed is not proof that
it is publicly available.

The local publishing scripts verify source refs, signatures, checksums and uploaded asset identities before publication, then verify the exact release by tag. A beta must be a prerelease with `make_latest=false`; confirm that the stable Latest release is unchanged. A local build or a draft is not a public release. Publish only as a separately authorized step and update the documentation's candidate status and `/latest` destination accordingly.

See [Release validation](release-qa-protocol.mdx) and [documentation maintenance](local-docs-development.mdx).

## Local desktop build

Run `scripts/build_desktop_release.sh` with the verified Python build environment. It prepares checksum-pinned Sparkle, builds and signs the app and nested components, notarizes and staples, creates the DMG, and creates `dist/desktop-update/` with the signed archive, feed candidate and checksums. It never publishes.

The Sparkle signing key stays in Keychain under account `cx.ap.glyphsMcp`, separate from the Developer ID certificate. Never export it into the repository. Application updates are separate from component migrations; acceptance must exercise a signed older-to-newer app update and component rollback.

The current development catalog adds `create_document` under `document.create.v1`,
bringing the public tool count to thirteen. See the current command reference
for creation and separate Save As behavior.
