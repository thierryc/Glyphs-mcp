## Implemented

- Skill detail dialogs use an icon-only Close control in a fixed header, a
  clean content layout and an All My Projects / One Project pill selector attached to
  the installation panel. Source and instructions open in a separate reader.
  Scope changes update selection immediately while receipt reads and folder
  hashing run off the main actor; stale scan results are discarded and skill
  mutations remain disabled until the current scan completes. Close and Escape
  retain loading/operation protection.
- Shared workflow cards with concise summaries, accurate target counts, one
  View details disclosure and main choices separated from More options. Visible
  cards reconcile stale choices and remove obsolete controls; text-only clients
  retain the same valid actions. The existing 30-second automatic Keep default
  remains, with a separate Pause countdown control and background checks that
  preserve elapsed time only for an unchanged result. Named-client compatibility
  still requires qualification in each client.
- Lightweight installer initialization, shared background payload extraction and
  verification, actual-stage status, slow-check explanation, retry/log controls,
  and first-presentation/preflight timing records. Skills shares the resolver.
- Eighteen tools, including `compare_fonts` without a live document. Compiled
  inputs are snapshotted and hashed; comparison runs in an isolated cancellable
  process and emits measured scope evidence and a verified local HTML report.
  Publication is create-only and verifies snapshots/report bytes. Exports keep
  their existing live-document guards.
- Optional managed installer infrastructure with archive/signature checks,
  transactional recovery, ownership protection, version detection and per-card
  controls. Neither optional tool is in Install All. Persistent Beztrace engine
  configuration is prepared as a separate source overlay.
- Pinned SDK `c0352321d30a06006f18e94d600f5caf43d06f1b`, dated official web
  snapshots, maintained file-format authorities, regenerated 1,100-document
  corpus, and synchronized eleven-skill agent package.
