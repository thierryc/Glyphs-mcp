# Glyphs MCP 2.8.0 / build 93

Unpublished local candidate for Glyphs 4, based on the published
[2.7.0 build 91](https://github.com/thierryc/Glyphs-mcp/releases/tag/v2.7.0).

## What’s new

- **Antigravity setup.** Setup detects Antigravity App and IDE and can configure their shared MCP connection and install global Glyphs skills. Setup reports connection and skill updates separately. Individual Antigravity copies also appear in Skills.
- **Beztrace setup.** Companion Plugins installs the Beztrace plugin and tracing engine as a pair. The plugin uses the included engine after Glyphs reopens, while previously selected engines stay in place. Repair can restore missing files in a managed engine.
- **Skill updates.** The Skills sidebar badge counts distinct skills with an available update across default and project locations. **Review Skill Updates** opens the filtered list. The installer verifies staged managed copies, keeps backups and records each completed update so a retry can pick up after an interruption.
- **Component reminders.** The reminder explains that it appears once per app version and build for that installation. **Dismiss This Reminder** leaves available updates visible in Setup.
- **Six desktop languages.** German, Spanish and Brazilian Portuguese join English, French and Simplified Chinese. The native app localizes dialogs, accessibility labels, plural forms and app-owned error messages. It follows macOS language preferences.
- **Tasks badges.** The dashboard sidebar and macOS status menu count visible Working and Waiting tasks. A zero count hides the badge. Finished tasks and tasks that need attention remain available in the Tasks panel.
- **Tasks refresh.** The panel keeps the last successful observation if a refresh fails. It shows **Could not refresh Tasks** for ambiguous failures and **Server stopped** when the connection failure is corroborated by a process check.
- **Small and Petite Caps.** The skill covers creation, continuation, refinement and audit. It describes per-master petite-cap height defaults, selective compensation, interpolation review and protection of manual corrections.

## Compatibility

The desktop, bridge, sidecar and four agent manifests use 2.8.0. The package includes 22 MCP tools and 15 managed skills, including Glyphs Switching Shapes. Lean interface revision and bridge protocol remain at 1. Curve Inspector and Reference Inspector retain their independent versions. Glyphs 3 remains on the separate 1.11.0 distribution.

## Local candidate

The unsigned desktop app is built at `dist/local/Glyphs MCP.app` with its source-bound `dist/local/build-receipt.json`. Signing, notarization, installed-runtime and signed-upgrade acceptance, and public release are separate steps. The published release remains 2.7.0 build 91.
