This is the canonical tool reference for the server shipped in this repo. The site navbar links to the current release/version; avoid copying the full command table into README or promotional pages.

The active tool list can be smaller than this page when the `Read-only` profile is selected in **Edit -> Glyphs MCP Server**. Reconnect your MCP client after changing profiles so it fetches the current `tools/list`.

Glyphs MCP supports both Glyphs 3 and Glyphs 4 from `main`. See [Glyphs 3 compatibility](./glyphs3-compatibility.mdx) for the known Glyphs 3 limits around sidebearings and export edge cases.

## Most used tools

- `get_server_info`: confirm runtime identity and open-font source-format metadata.
- `list_open_fonts`: list open fonts, their source format, and pick a `font_index`.
- `get_font_masters`: find master IDs.
- `get_custom_parameters` / `set_custom_parameters`: inspect or guardedly update font/master custom parameters without implicit saving.
- `get_selected_font_and_master`: confirm current font, master, and selection.
- `review_unicode_assignments` / `apply_unicode_assignments`: review and safely apply Unicode mappings.
- `review_spacing` / `apply_spacing`: review, dry-run, and apply spacing changes.
- `generate_kerning_tab`: open a kerning proof/worklist tab.
- `review_kerning_bumper` / `apply_kerning_bumper`: audit and apply conservative collision fixes.
- `review_italic_first_pass` / `apply_italic_first_pass`: preview and apply an experimental construction draft for a Roman's emphasis companion; the tools do not claim to produce a finished italic.
- `set_curve_review_overlay` / `get_curve_review_overlay_state`: control and verify the native signed-curvature Reporter in Glyphs Edit View without changing the font.
- `render_glyph_review_image`: render a legacy read-only PNG proof image; its curvature overlay is deprecated in favor of the native Reporter.
- `review_tunni_geometry` / `apply_tunni_balance`: inspect and safely balance explicit cubic segments.
- `review_curve_quality`: return bounded curvature metrics and conservative warnings.
- `preview_tunni_balance_candidate` / `review_outline_candidate_session` / `accept_outline_candidate_session`: preview in Edit View, review the exact state, and promote a token-bound candidate.
- `materialize_outline_candidate_session`: create editable native layers only when manual adjustment is wanted.
- `add_glyph_annotation` / `clear_glyph_annotations`: place and remove MCP-managed native Glyphs annotations.
- `docs_search` / `docs_get`: fetch focused Glyphs docs on demand.

## Discovery and inspection

Glyph and layer inspection responses may include Glyphs show links:

- `showUrl`: native `glyphsapp://show/` URL.
- `showHttpUrl`: local bridge URL.
- `showMarkdown`: Markdown link form suitable for agent responses.
- `showUrlUnavailableReason`: returned when an unsaved font cannot produce a stable link.

The native curvature Reporter uses teal (`#009E9E`) for positive signed
curvature and pink (`#DB2E8C`) for negative curvature. Both signs are placed by
curvature magnitude along the path right normal, so correct Glyphs winding
sends outer-contour combs outward and counter combs into counter space. It
draws teeth plus connected, sign-split envelope runs at `0.65` alpha; reversing
a path reverses the placement side and signed color. The native defaults are 51 samples per
cubic, a `0.010` length scale, and a `0.12em` normal clamp with a `0.25em` hard
guard. Sampling reduces deterministically before the 2,000-stroke frame cap.
Path-targeted reviews and the Reporter analyze raw editable paths only and
report components omitted from the calculation.

The Candidate Reporter leaves the normal Glyphs outline visible and draws only
the source/candidate symmetric difference. Current proposals use warm golden
yellow; stale proposals use coral red and show a `STALE` legend. Identical
geometry produces no glyph-area drawing. Curvature stays in the independent
Curvature Reporter. Detached previews are capped at 16 sessions, 256 entries,
and 100,000 nodes; oversized previews fail instead of truncating.
Materialization is optional and never uses backgrounds. Candidate-layer and
font manifests allow materialized sessions to be recovered after restart.

## Codex and ChatGPT feedback panel

These tools share the versioned `ui://glyphs-mcp/feedback-v1.html` MCP App
resource. Non-UI clients receive the same information as concise text plus
structured output. The panel is a review and feedback surface, not an editor.
It follows host light/dark theme variables and uses a standard server-tool
bridge with an OpenAI compatibility fallback for actions such as **OpenType
Features** and **Refresh**.

See [Codex and ChatGPT plugin UI](../getting-started/codex-chatgpt-plugin-ui.mdx)
for installation, screenshots, supported states, action behavior, and safety
boundaries.

| Tool | Description |
| --- | --- |
| `show_glyphs_status` | Show server, Glyphs, and open-font status. |
| `show_font_feedback` | Show bounded, read-only information for an open font. |
| `show_glyph_feedback` | Show glyph metadata, dimensions, sidebearings, anchors, components, layers, and warnings without outline paths. |
| `show_opentype_features` | Show OpenType feature state, warnings, line counts, and parsed stylistic-set substitutions; code is omitted unless requested. |
| `preview_spacing_feedback` | Run spacing with `dry_run=true` and create a short-lived reviewed plan. |
| `preview_kerning_feedback` | Run kerning bumper analysis with `dry_run=true` and create a short-lived reviewed plan. |
| `preview_handle_smoothing_feedback` | Run collinear-handle smoothing with `dry_run=true` and create a short-lived reviewed plan. |
| `apply_feedback_plan` | From the app, re-run the dry run, compare its canonical change-set hash, consume the plan, and apply only after explicit confirmation. |
| `open_feedback_target` | From the app, open only resolved glyph/layer objects belonging to an already open font. |

Feedback plans expire after ten minutes, are capped at 64 process-local plans,
and are never persisted. Every apply attempt consumes its plan before mutation.
Stale state, partial results, failure, or an uncertain transport outcome requires
a new dry run. None of these tools saves a font.

## Custom parameters

| Tool | Description |
| --- | --- |
| `get_custom_parameters` | Read font, master, or effective master-over-font parameters; filter by exact names or prefix and report duplicates without collapsing raw records. |
| `set_custom_parameters` | Preview explicit font/master sets and deletes. Mutation requires `dry_run=false` and `confirm=true`, rejects targeted duplicates and non-JSON values, redraws, verifies read-back, and never saves. |

Use `null` to request deletion. Master and effective scopes require an explicit
`master_id`; call `get_font_masters` first when needed. The setter defaults to a
dry run so an agent can present the exact changes before confirmation.

## Unicode assignments

| Tool | Description |
| --- | --- |
| `review_unicode_assignments` | Review complete font mappings, collisions, invalid values, previous-map changes, and optional deterministic allocations. BMP PUA is the default range, not an icon-font mode. |
| `apply_unicode_assignments` | Apply explicit assignments after expected-state and whole-font collision preflight; supports `dry_run`, requires `confirm=true`, verifies read-back, rolls back failures, and never saves. |

Use the review tool in either profile. The apply tool is available only in `Edit`.
Selection is the default target, but every review scans the complete font map for
collisions. Pass `scope="font"` explicitly for a whole-font target or provide
`glyph_names`.

PUA values require a private agreement outside Unicode. They can support icon
fonts, gaiji, historical or experimental characters, legacy mappings, and other
closed character sets. Do not use PUA merely for swashes, small caps, contextual
forms, localized shapes, ordinary ligatures, or components; those normally
belong in OpenType features, character sequences, or unencoded glyphs.

See [Unicode assignment tools](../contributor/unicode-assignment-tools.md) for
the input contract, previous-map format, safety model, and usage boundaries.

## Editing and outlines

Italic first-pass tools use the Glyphs source/Transformations angle convention: positive `angle` values lean Latin outlines to the right. The default is `12.0`, chosen as a modern common working default. Exported OpenType/UFO metadata uses the opposite sign convention, so a Glyphs `+12` degree source angle corresponds to about `-12` in `post.italicAngle` or an OpenType `slnt` axis value.

This workflow is experimental design assistance. It helps establish a
controlled starting point for an italic that complements the Roman in
emphasized text; it does not replace optical drawing, spacing, kerning,
alternates, or proofing.

`slant_mode` accepts `raw`, `cursivy`, or `balanced`. Balanced defaults to
`curve_strength=0.75` and `stem_compensation=1.0`; both strengths must be
between `0` and `1`. It builds Raw, applies the pure-Python straight-stem
correction at partial strength, interpolates those compatible coordinates, and
then applies the requested final compensation. The controls are independent:
at `stem_compensation=1`, accepted stems converge to their Roman perpendicular
width, which can make the intermediate `curve_strength` blend visually subtle.
Balanced never calls the Glyphs Transformations filter.

Review executes the full pipeline on detached layer copies. Balanced recursively
checks component chains and blocks reflected, rotated, non-uniformly scaled,
cyclic, unreadable, or component-master-mismatched constructions when they do
not commute with the requested shear. The reviewed batch is all-or-nothing;
rerunning with an explicit `skip_glyphs` list is a designer decision. The
three-family benchmark promotes Balanced as the recommended experimental
deterministic option. Omitted `slant_mode` calls remain Cursivy-compatible.

`path_index` values. Cubics are identified by their curve end-node index.
Review can scan the whole path, but apply always requires a unique explicit
segment list. See the [cleanroom geometry record](../contributor/curve-geometry-cleanroom.mdx)
for formulas, conservative eligibility limits, and provenance.

## Docs helpers

| Tool | Description |
| --- | --- |
| `docs_search` | Search the official Glyphs API, scripting, plug-in-template, version 3/4 format, and schema references; results include source kind, format version, and URL. |

## Export and execution

| Tool | Description |
| --- | --- |
| `ExportDesignspaceAndUFO` | Export UFO masters and designspace documents with structured logs and errors. |
| `execute_code` | Execute arbitrary Python in the Glyphs context. |
| `execute_code_with_context` | Execute Python with injected helper objects such as font, glyph, and layer. |
| `save_font` | Save the active font without requesting format conversion; reports format version before and after. |

Execution notes:

- Prefer dedicated tools when they fit.
- Prefer `execute_code_with_context` for glyph-scoped scripts.
- Use `snippet_only=true` when you want a Macro Panel snippet instead of automatic execution.
- Bound large outputs with `max_output_chars` and `max_error_chars`.
- Avoid `exit()`, `quit()`, and `sys.exit()`.
- Large glyph edits should use Glyphs undo/change wrappers inside the script.

## Safe starter prompts

### Health check

```text
Call list_open_fonts and tell me how many fonts are open.
If you see an error, quote it verbatim.
```

### Spacing review

```text
Review spacing for my current selection.
Rules: read first, do not auto-save, and do not mutate without a dry run.

1. Call review_spacing with {"font_index":0,"defaults":{"referenceGlyph":"auto"},"guards":{"negativeBearingPolicy":"guarded","warnBelowEm":-0.05,"blockBelowEm":-0.10}}
2. Verify resolved references and blocking/manual-review assessments.
3. Call apply_spacing with the same arguments plus {"dry_run":true}.
4. Stop and wait for approval before using confirm=true. Apply only eligible results and disclose any named override.
```

### Kerning collision review

```text
Review kerning collisions or near-misses in my current font/master.
Rules: do not mutate anything.

Call review_kerning_bumper with {"font_index":0,"min_gap":5,"relevant_limit":2000,"include_existing":true,"scan_mode":"two_pass","dense_step":10,"bands":8,"result_limit":200}
Summarize the 20 worst findings and likely next steps.
```

### Focused docs lookup

```text
Search the bundled Glyphs docs for "GSLayer bounds".
Call docs_search first, then docs_get for the best match.
Summarize only the details needed for this task.
```
