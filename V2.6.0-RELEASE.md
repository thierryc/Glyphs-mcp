# Glyphs MCP 2.6.0 / build 75

This is the 2.6.0 release candidate for Glyphs 4. The published stable download
is 2.5.1/build 74. [2.5.1 release](https://github.com/thierryc/Glyphs-mcp/releases/tag/v2.5.1)

## Changes

- Glyphs Health shows workload and connection health in the companion app and
  reports it to agents. A configurable open-font threshold provides a warning.
  Critical pressure or delayed Glyphs dispatch can defer expensive work until
  the editor recovers. [Glyphs Health](docs/glyphs-health.md)
- Glyphs Small and Petite Caps derives editable Latin caps from uppercase.
  Review a pilot before extending it. The workflow preserves existing
  destinations and manual corrections.
- Path Doctor can fit selected closed polygon outlines to curves within a
  measured error budget. It checks master correspondence and holds outlines
  that cannot satisfy the geometry checks. [Polygon fitting qualification](reports/path-fitting-20261104.md)
- Cancelled script previews and eligible abandoned previews release their
  reservations. Tasks with unresolved edits keep their recovery options.
- The Skills dialog manages copies across projects on this Mac, by agent, or
  inside individual project folders. Matching copies show a circled version
  check and keep **Reinstall** available. **Update** is highlighted when a
  managed copy differs from the available package. Linked skills stay verified
  when Python generates cache files.
- **Project copies** shows only folders with their own copy of the selected
  skill. Paths and actions stay visible, including **Remove from project…**.
  Agents with a Mac-wide copy can use it in any project. An orange warning
  marks unavailable folders in **My Project** and beside previously detected
  project copies.
- Skills supplied by the Glyphs MCP plugin for Cursor link directly to the
  plugin controls in **AI Agents**. Catalog skills can show their own version
  and the agents they were tested with. All compatible agents can install them,
  and community entries link to GitHub for feedback. [Skills guide](content/getting-started/use-agent-skills.mdx)
- The Glyphs server panel confirms the configured endpoint before enabling
  **Copy URL**. Desktop Settings follows the saved port while preserving
  edits in progress. The default local MCP URL is `http://127.0.0.1:9680/mcp/`.
  For a custom port, use **Edit → Glyphs MCP Server… → Copy URL**.

## Compatibility

The candidate bundles 14 managed skills and exposes 22 MCP tools, including
the optional workflow display tool. It uses lean interface revision 1 and
bridge protocol 1. Update the desktop app, bridge, sidecar and agent package
together. Glyphs 3 uses its separate 1.11.0 release. [Version and identity](content/reference/version-identity.mdx)

## Qualification

An earlier build 75 source snapshot passed the frozen release gate with 3,458
Python tests and 327 desktop tests. The later port changes passed 29 focused
tests and the documentation build. Local Skills checks used a scratch project
to verify installation, unavailable-folder warnings, and removal with backups
while the Mac-wide copies remained available.

The final Skills source passed 343 desktop tests, catalog validation and six
catalog tests, the documentation build, and the managed skill synchronization
and package checks.

Loaded Glyphs performance and safety acceptance, clean installation, the
signed upgrade from 2.5.1, and distribution verification are release gates.
Record results against the exact artifacts tested. [Candidate gates](V2.6.0-PREPARATION.md)
