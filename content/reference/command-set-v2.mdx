The canonical v2 reference is now [The v2 tools](command-set.mdx). This page remains available for existing repository links.

The tools are `get_status`, `list_tasks`, `list_documents`, `create_document`, `duplicate_document`, `open_document`, `import_document`,
`activate_document`, `open_edit_tab`, `close_document`, `read_entities`, `start_job`,
`compare_fonts`, `get_job`, `apply_job`, `accept_job`, `discard_job`, `save_document`,
`start_edit_workflow`, `get_edit_workflow`, and `respond_edit_workflow`. These
twenty-one data/action tools do not open cards. The additional read-only
`show_edit_workflow` opens an optional card when its evidence or controls add value.

Start with the [first session](../tutorial/first-session.mdx) or read the
[complete signatures, selectors and job kinds](command-set.mdx). Application is
save-free; `accept_job` performs verified whole-document persistence after
review, while recovery and native history retain exact values.

## Path Doctor

`path_diagnostics` uses `start_job` / `get_job` with `path.diagnostics.v1`.
Options select `glyphs: "all" | [names]`, `layers: "all_masters" | [exact IDs]`.
The read-only sliced live job accepts dirty/pathless fonts, never saves, excludes
backgrounds/history/component expansion, and returns diagnostic evidence with
coverage, stable issue IDs, full state guards and qualified repair proposals.

`normalize_closed_seam` is an explicit `outline_edit` operation with `path` and
`stateHash`, requiring `outline.normalize-closed-seam.v1`. It preserves the real
incoming line/cubic and profiles; conflicting profiles, locks and unsupported
references are held. It never changes fill/smoothness. Repair availability is
native-qualification gated; a diagnostic proposal does not authorize mutation.
See the Path Doctor skill and `docs/path-doctor-architecture.md`.
