---
title: Glyphs 3 and v1 compatibility
---

The Beta 3 desktop installer is **Glyphs 4-only**. It no longer embeds the
Glyphs MCP 1.11.0 plug-in, its runtime or `skills-v1`.

Glyphs 3 remains supported by the separate pinned v1.11.0 release. Its source
metadata, runtime, dependencies, tool catalog and documentation remain separate
from the lean Glyphs 4 candidate.

Use the [v1 documentation](/docs/), including its [installation instructions](/docs/getting-started/installation), [command catalog](/docs/reference/command-set) and [Glyphs 3 compatibility details](/docs/reference/glyphs3-compatibility).

The v1 compatibility page covers native dependencies such as **Sidebearings** and **ExportDesignspaceAndUFO**. Those legacy integrations do not imply equivalent v2 MCP endpoints. V2 has the [seven-tool contract](command-set.mdx).

When using both Glyphs versions, install each from its appropriate distribution,
connect the client to the intended server and avoid running two servers on the
same MCP port. Product version 2.0.0 identifies the new architecture, not the
pinned Glyphs 3 plug-in.
