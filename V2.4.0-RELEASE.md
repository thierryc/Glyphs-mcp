# Glyphs MCP 2.4.0 — published qualification

Published **2.4.0/build 71**, stable channel, signed tag `v2.4.0`.
The tag binds source commit `c9f53527`, including the typed-export instance fix
and its normal merge into the task-management release. Prior signed releases,
assets and tags remain intact.

## Changes

- Retain typed-export instance selection after native recovery regenerates live
  IDs. Verify the complete ordered instance collection and immutable source
  before resolving a unique saved slot; reject drift or ambiguity without
  saving or rewriting the font. Include both identities in the export report.
- Show creation dates in task rows and start, last-activity and expiry dates in details.
- Add **Settings → Tasks → Expire inactive tasks after**, default **1 day**,
  with 7-, 30- and 90-day choices. Close abandoned intent as Expired while
  preserving unknown/partial outcomes and diagnostics. Protect active work and
  usable recovery; cancel only unapplied previews. Stop overdue queued intent
  before it can execute. Preference changes apply without a server restart.
- Simplify Tasks into **Needs attention**, **Active** and **Finished**.
  Distinguish Working from Waiting, and show outcomes separately from recovery.
- Let independent fonts continue while another document retains script recovery,
  including after confirmed stopped partial execution. Keep same-document
  recovery decisions and protections for active execution, cleanup and unknown
  outcomes.
- Explain each blocker with its owning task, affected font, resource scope and
  whether it clears automatically or requires a decision. Add **View blocking
  task** to the native Tasks window.
- Accept busy requests as **Waiting** and resume them automatically without
  closing unrelated recovery. Preserve document order and preview authorization;
  keep intake, inspection and cancellation responsive during native calls.
- Present existing modified or unowned skills as successfully preserved
  information under **Configured**, with a positive setup summary. Real
  configuration errors retain their failure state.
- Preserve live recovery records during operation pruning. Stop advertising
  cached memory recovery after a known bridge restart or lost operation.
- Keep partial failures and incomplete typed recovery visible for inspection.
  Fold associated preparation and prerequisite-save steps into their request.
- Allow staged exports to publish independently of live font work. Show export
  destination conflicts in Tasks and keep them retryable with a new destination.
- Update English, French and Simplified Chinese interface copy and synchronize
  the shared agent-package guidance.
- Include Glyphs Hinting among the twelve managed skills, with source/binary hint inventories and controlled rendering comparisons.

## Qualification

The complete release gate passed **3,267 Python tests** (two expected skips),
**312 desktop tests**, the documentation build, deterministic payloads, managed
skills and package checks. Both private runtimes passed startup and HTTP/stdio
checks. Product version is 2.4.0, installer build 71, with 22 tools, 12 managed
skills, interface revision 1 and bridge protocol 1.

Apple accepted the expanded payload, final universal app and disk image.
Developer ID signatures, hardened runtime, timestamps, notarization tickets,
Gatekeeper, nested code, component identities, signature-preserving installation
copies and the signed desktop-update archive/feed all verified. The final
read-only mounted DMG passed visual review.

The exact signed payload passed **37 isolated native Glyphs checks**: 22 queue,
independent-font recovery and restoration checks, and 15 expiry checks. These
used disposable fonts in separate Glyphs 4.2/build 4202 scripting processes.
Native generation/exports for the typed fix retain their separately recorded
static-instance acceptance; all five export modules in this signed payload
match the merged source exactly. See [typed-export evidence](reports/typed-export-instance-binding-20261027/README.md).

All **six GitHub assets** passed digest/size verification and anonymous public-download checks before promotion of the exact signed update feed.

## Acceptance scope and retained limits

The installed manager, editor, native bridge, sidecar and existing user task
records were not replaced by this release workflow. Native font checks used
isolated disposable fixtures; they are separate from the earlier build-70 live
MCP acceptance recorded during preparation. Native Save used a standalone
fixture writer rather than the editor's NSDocument save path.

No fresh full GUI updater/VM run was performed. The updater implementation is
unchanged; prior signed-update/VM evidence retains its original version scope.
Intel runtime execution used Rosetta; physical Intel hardware was not tested.
The retained typed-export acceptance covers static OTF/WOFF2 instances and does
not certify variable-instance exports.

See [publication evidence](reports/release-2.4.0-candidate/README.md) and the
[frozen preparation record](https://github.com/thierryc/Glyphs-mcp/blob/v2.4.0/V2.4.0-RELEASE.md).
