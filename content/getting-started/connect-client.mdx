---
title: Connect an AI application
---

The installer can optionally connect detected AI applications. The native components and the AI connection are separate choices: install the components first, then connect a client to the server.

## HTTP connection

1. Start the server through **Edit → Glyphs MCP Server…**.
2. Copy its MCP URL. The default is `http://127.0.0.1:9680/mcp/`.
3. Add that URL to a local client that supports **Streamable HTTP MCP**, or use the installer's supported connection option.
4. Refresh the client's tools and call `get_status`, then `list_documents`.

A correct v2 connection exposes exactly these nine tools: `get_status`,
`list_documents`, `read_entities`, `start_job`, `get_job`, `apply_job`,
`accept_job`, `discard_job`, and `save_document`. If you see the older v1
catalog, check which server and port the client is using.

The bridge port 9681 is internal and is not an MCP endpoint. The loopback URL refers to this Mac: a remote cloud client cannot reach it directly. This guide does not configure a public tunnel.

## Optional agent plugin

The matching 2.0.0 agent package adds workflow skills and connection metadata. It does not install the Glyphs components. For the local candidate, use the matching supplied package, not an older marketplace package. See [Skills and optional plugins](use-agent-skills.mdx).

The v2 tools return structured results and reports. A v1 embedded feedback
interface is not part of the nine-tool contract; review applied results in
Glyphs and use `accept_job` to persist them. `save_document` is reserved for an
explicit document that has no active or applied MCP job.

## After a change

If you change the MCP port, update the client's connection. After installing new native bundles, restart Glyphs. After changing an agent package, refresh the client according to its own settings. Keep one intended server per MCP port and avoid duplicate connections to the same server.
