# Glyphs MCP 2.5.1 / build 74

Stable patch candidate for coordinated Path Doctor cleanup and native visual
review. Publication requires the signed/notarized artifact checks; this document
does not by itself claim public availability.

Path Doctor adds exact consecutive duplicate removal, independent seam
normalization, redundant line-node cleanup and bounded native optimization for
closed filled line/cubic outlines. Correspondence is preserved across ordinary
masters, brace layers and complete bracket branches. Conflicts, unsupported
special layers and unresolved geometric checks are held. Native sampling is
reported as sampled coverage rather than a continuous designspace guarantee.

The existing workflow card has compact cleanup rows, exact/bounded mode,
numeric tolerance controls, result counts and optional native comparison help.
The normal flow remains configure, apply, compare against Last Saved, keep or
undo. Cleanup does not silently save. Pen-profile optimization and De-kink retain
their separate workflows. Native cleanup qualification is limited to Glyphs
4.2/build 4202 and the qualified selector set.

Source/native qualification is recorded in
[Path Doctor cleanup](reports/path-cleanup-20261101.md). Eight detached native
fixture cases passed. Installed Apply/Undo removed one duplicate from a generic
five-node square and restored all five nodes with the original coordinates and
flags. Live capability discovery and the all-master read-only scan passed.
The final card redesign passed 50 workflow UI tests. The focused release gate
includes the cleanup, protocol, bridge, workflow/card and recovery suites.

The optional online skill and immutable catalog pin were published through
`thierryc/glyphs-mcp-skills` PRs #7 and #8. The app retains 22 public tools,
13 managed skills, protocol/interface revision 1 and independent companion
versions. Glyphs 3 remains pinned to its separate 1.11.0 release.

No private font files, geometry, recovery captures or screenshots are included
in the source or release artifacts. Native Save can reduce arbitrary numeric
precision. Physical Intel hardware and a fresh full GUI VM updater matrix are
not claimed; retained baseline evidence keeps its original scope.
