# Historical native probes

The `native-4108-*`, `engine-source-4108-*` and `native*_probe.py` files preserve development evidence from Glyphs build 4108 and the explicitly named Curve Inspector revisions. Some records include expected or unresolved failures. They are not current release acceptance gates, and the scripts are maintainer probes rather than user installation steps.

Use `release-0.5.1.json`, `candidate-status.json` and the current product release qualification for their specific scope. Workstation paths in newly committed probe records are normalized; the original local files were preserved in the repository cleanup recovery archive.
