# Glyphs MCP 2.0.4 / build 60 — local distribution

Prepared on 2026-10-12 for the user affected by Python installation detection. This is a local Developer ID signed and Apple-notarized distribution. It has not been published, tagged, pushed or sent to another person. No public update feed was modified.

## Included fixes

- Resolve the official Glyphs 4 Python module when the selected app's framework preference is absent. Retain explicit selections, including empty/broken selections; do not silently replace them.
- Allow installation after an inconclusive Python check, while retaining payload, transaction, idle-service and closed-font guards. Never label a skipped check as verified.
- Keep setup preparation and Python status inside Setup, with clear status/actions and collapsible technical details.
- Show a Glyphs 4 copy selector only when multiple distinct supported copies are detected. Remember the selection, identify its Python, cancel/reset old checks, and reject stale results. All Glyphs 4 copies must close before shared plugin replacement.
- Generate fonts using Glyphs Python and verify tables, containers and shaping using the private MCP Python. The default Glyphs Python does not need FontTools or HarfBuzz installed into it.
- Persist bounded, correlated installation diagnostics: selected and discovered app paths/domains, preference state, module candidates, native Python identity, process results, failure reasons and payload context. Redact account prefixes and common credentials.
