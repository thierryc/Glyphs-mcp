# 2.5.0/build 73 qualification evidence

The candidate has 22 tools, 13 managed skills, interface revision 1 and bridge
protocol 1. The signed release tag is `v2.5.0`. Build 72 was superseded locally
after expanded native qualification exposed metadata-container recovery that
Glyphs' Python wrapper could not read. It was never published. Build 73 restores
native nested containers without rounding numeric attributes or changing profiles.

The final signed payload passed eight generic Path Doctor groups and a two-master,
12-layer fixture with four qualified seams and four conflict/lock holds.
Independent checks cover exact geometry, profiles/defaults, non-target data,
selective recovery, stale refusal, idempotence and native-persistence differential
comparison. The nine-master outline regression also passed apply, cancellation,
partial-failure rollback, Undo/Redo, discard, save/reopen, native node removal,
selection, hints, components, anchors and authored metadata. Loaded implementation
modules were verified inside the extracted signed payload.

Both exact signed runtimes passed packaged-installer, startup, HTTP/stdio, tool
catalog and optional-card resource checks. Startup was 4.290 seconds on arm64
and 9.815 seconds on x86_64 via Rosetta. These measurements do not stand in for
native edit responsiveness. The locked runtime SDK passed all 23 feedback tests.

Privacy inspection covered 15,797 payload files. The 46 font/example entries
are byte-identical to already-public development SDK fixtures in v2.4.0.
No private owner fonts, profiles, screenshots, local qualification folders or
generated test copies are included. Older distributed guidance now uses generic
private-fixture labels; detailed private instance bindings and source fingerprints
are kept in local evidence, with only aggregate export results retained publicly.
Historical release tags are unchanged.

Apple acceptance, final signatures/tickets, disk-image inspection, the frozen
source publication gate and anonymous public-download results are completed and
recorded before feed promotion. The adjacent aggregate JSON files record actual
native results and package provenance; publication evidence is added after the
public assets are verified.

The installed manager, editor, bridge, sidecar, open fonts and task records were
not replaced by qualification. Native checks used isolated original generic
fixtures. Native Save can reduce arbitrary live-coordinate precision. Other
Glyphs hosts remain diagnostic-only for seam repair. No fresh full GUI updater/VM
matrix or physical Intel test is claimed; retained acceptance keeps its version
scope. See the [release record](../../V2.5.0-RELEASE.md).
