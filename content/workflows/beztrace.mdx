---
title: Install and use Beztrace in Glyphs
---

Beztrace turns images into editable outlines and matches outlines across font
masters. Glyphs MCP installs the Glyphs plugin and connects it to the included
tracing engine in one setup flow. After reopening Glyphs, the plugin uses that
engine automatically.

## Install Beztrace

1. In **Glyphs MCP**, select **Companion Plugins** in the sidebar. Under **Optional
   plugins**, find **Beztrace** and choose **Set up Beztrace…**.
2. Follow the prompts for Glyphs Python and close Glyphs if it is open. Save any
   open fonts when Glyphs prompts you.
3. Choose **Install Beztrace**, then **Open Glyphs** when setup finishes.

Beztrace is a separate choice from **Install All**. Managed setup requires an
Apple silicon Mac with macOS 26.6.2 or later, Glyphs 4.1 (build 4107 or later),
and Glyphs Python 3.9 or later. Beztrace runs inside Glyphs independently of the
MCP server.

## Trace your first image

1. Open a glyph in Edit view and choose **Path → Beztrace…**.
2. Select an image and click **Update Preview**. Adjust the settings and inspect
   the outline.
3. Click **Apply to Layer** when you want to add the outline to the glyph.
   Preview leaves the font untouched. Apply updates the open font, which you
   can save in Glyphs when ready.

For master matching, choose **Path → Beztrace Match Masters…**. See the
[Beztrace guide](https://github.com/thierryc/beztrace/blob/3294e200d18c502b4d3b36d1ec48e3a6809ea1e4/Companions/Glyphs/README.md)
for the four available modes and their inputs.

## Updates and existing installations

- **Update Beztrace…** upgrades a Glyphs MCP-managed copy and connects it to the
  new included engine. This also updates managed copies that previously
  required manual engine selection.
- **Check existing setup…** appears when Glyphs MCP finds a separately installed,
  modified, or development copy. Check the **Path** menu in Glyphs to use it.
  Keep a backup outside the Plugins folder if you choose to remove it yourself
  before switching to the Glyphs MCP-managed copy.
- **Remove Beztrace…** removes a managed plugin and its managed engine setting.
  Engine files and personal choices are kept.

The current catalog pairs the signed
[Beztrace plugin 0.2.2, build 27](https://github.com/thierryc/beztrace/releases/tag/glyphs-v0.2.2)
with the signed [Beztrace engine 0.2.2](https://github.com/thierryc/beztrace/releases/tag/v0.2.2).
Each desktop release uses the catalog that shipped with it.

## Troubleshoot engine settings

A previously saved custom engine takes priority over the included one. If that
engine is missing, restore it or use **Additional actions… → Choose engine…**
in Beztrace to pick a working engine. To return to the managed default, close
Glyphs, back up
`~/Library/Application Support/beztrace/engine-settings-v1.json`,
and remove the `userEngine` entry while keeping the rest of the JSON. Reopen
Glyphs and try a preview again.

If the settings file is unreadable, close Glyphs and move it aside as a backup.
Then choose **Repair Beztrace** from the Beztrace setup sheet to recreate the
managed setting.
