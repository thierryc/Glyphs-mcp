# Example prompts and expected results

- “Plan a two-style Latin display font for book covers.” Expected: a concise brief
  with audience, style count, uses, missing language coverage and deliverables.
- “Turn these client requirements into a font project brief.” Expected: preserve
  the supplied requirements, list unresolved decisions and identify success criteria.
- “Fix this glyph's handles.” Should not invoke this skill; this is an outline edit.

Before submission, test your own prompts in each claimed client and record the
client version, invocation evidence and result. The template itself is a starter,
not a reviewed catalog entry.
