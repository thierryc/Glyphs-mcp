# Glyphs MCP 2.0.4 / build 61

The release fixes Python detection and FontTools export with the official Glyphs Python module, adds an installation override after a failed check, improves Setup layout and diagnostic logs, and lets users choose their Glyphs 4 copy when multiple copies are detected. Explicit Python selections are preserved. Glyphs 3 remains the separate pinned 1.11.0 release.

Build 60 was a signed private candidate. Build 61 refreshes packaged release guidance for publication; the application fixes are unchanged. The full gate runs with user-site packages disabled to avoid unrelated PyObjC reload contamination. Old release/tool-count expectations and a script-cleanup fixture were corrected without weakening the guarded production lifecycle.

The release uses universal Developer ID-signed binaries and separately notarized payload, app and disk image. Final acceptance records and SHA256SUMS accompany the locally prepared distribution. No verification from the private candidate is mislabeled as an exact signed build-61 result.

Qualification commands:

- `PYTHONNOUSERSITE=1 scripts/run_local_release_tests.sh` (full Python, desktop, documentation, deterministic payload and both private runtimes).
- The normal Release build/sign/notarize, disk-image and local signed-update scripts.
- `scripts/verify_release_artifacts.sh --tag v2.0.4 --write-checksums` for exact final signatures, tickets, Gatekeeper, identities, archive contents and checksums.
- Signed VM installation and six static export outputs with Glyphs 4.1.1/build 4108 and official Glyphs Python 3.14.6. Native table and shaping verification executes in the private MCP Python; neither FontTools nor HarfBuzz is required inside Glyphs Python.

Physical Intel execution and exact macOS 14.0 execution remain unverified. Any live bridge test blocked by the VM's trial modal is reported separately from headless export acceptance. Previous releases, signed feeds and private build-60 artifacts are preserved.
