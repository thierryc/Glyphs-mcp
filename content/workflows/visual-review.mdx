title: Visual glyph review
description: Review curvature natively in Glyphs Edit View and use legacy PNG proofs for other overlays.
---

Use this workflow when an agent needs visual evidence before judging outlines, curvature, spacing, sidebearings, anchors, guides, or component composition.

## Native curvature overlay

Curvature review now uses the Reporter built into the Glyphs MCP plug-in. Enable
it with `set_curve_review_overlay(enabled=true)` or choose **View > Show Glyphs
MCP Curvature**. It draws directly over the active Edit View glyph, updates when
nodes move, and remains available while the MCP server is stopped.

- Teal (`#009E9E`) teeth and envelope runs show positive signed curvature;
  pink (`#DB2E8C`) shows negative signed curvature. Both use `0.65` alpha so the
  outline remains visible beneath the review drawing.
- Placement uses curvature magnitude along the path right normal. With correct
  Glyphs winding, outer-contour combs point outside the black shape and counter
  combs point into the white counter. Reversing a path reverses the placement
  side and signed color; magnitudes are unchanged.
- The editor renderer starts with 51 samples per cubic, reduces sampling
  deterministically, and enforces a 2,000-stroke frame cap.
- Display length uses a `0.010` linear scale, normally clamps to `0.12em`, and
  cannot exceed the `0.25em` hard guard.
- Raw editable paths are analyzed. Components are not expanded.

Call `get_curve_review_overlay_state` to confirm whether the Reporter is loaded
and active and to inspect its bounded last-draw record: glyph/layer, cubic and
stroke counts, clamp/cap state, cache status, and omitted components. Both MCP
controls change only global UI display state; they never dirty or save a font.

```json
{
  "enabled": true
}
```

The PNG `curvature` overlay is deprecated and is no longer the recommended
curve-review path.

## Legacy PNG proofs

The `render_glyph_review_image` tool is read-only. It renders an in-memory PNG response through MCP image content and does not write files, add guides, edit glyph data, or save the font.

After a successful render, the agent must display the returned MCP image content
directly in the chat. JSON metadata, a text summary, and an `Open in Glyphs`
link are not substitutes for the image. Glyphs show links only navigate to the
glyph or layer inside Glyphs; they do not display the rendered PNG.

## When to use it

- After an outline or spacing proposal, before calling a mutating tool.
- After a dry run, to give a vision-capable model a reviewable proof image.
- When numeric path JSON is not enough to judge visual balance.
- When components, anchors, guides, or selected nodes need visible context.

## Inputs

The tool uses the current selection when `glyph_names` is omitted. Pass names explicitly when reviewing a stable list.

Common overlays:

- `metrics`: baseline, x-height, cap height, ascender, and descender.
- `sidebearings`: origin and advance-width lines.
- `bounds`: layer bounds.
- `nodes` and `handles`: outline point review.
- `anchors`: anchor crosses.
- `guides`: existing layer guides.
- `curvature`: deprecated PNG compatibility overlay. Prefer the native Reporter.

Curvature metadata reports its sign formula, normal convention, color entries,
the right-normal outside-ink placement rule, `0.25em` comb-length clamp, stroke
count/limit, and any deterministic uniform sample reduction under the hard
stroke cap. The legacy PNG retains 51 samples per cubic, a `0.02` scale, and a
`0.25em` clamp while applying the same right-normal placement correction.
The 1.7 overlay does not use adaptive sampling; adaptive curve analysis is
reserved for 1.8. Components can still appear in the filled black proof when
`include_components=true`, but they are not expanded into curvature segments.
Check the top-level and per-glyph `componentCountOmitted` values before using
the comb to assess a composite glyph.

## Sample tool calls

Review the current Glyphs selection with default overlays:

```json
{
  "font_index": 0
}
```

Review named glyphs with outline details:

```json
{
  "font_index": 0,
  "glyph_names": ["A", "B", "O"],
  "columns": 3,
  "image_width": 1600,
  "include_components": true,
  "overlays": ["metrics", "sidebearings", "bounds", "nodes", "handles", "anchors", "guides"]
}
```

Legacy PNG curvature compatibility call:

```json
{
  "font_index": 0,
  "glyph_names": ["S", "O"],
  "overlays": ["nodes", "handles", "curvature"]
}
```

Request a base64 fallback in metadata for clients that do not surface MCP image content:

```json
{
  "font_index": 0,
  "glyph_names": ["n", "o", "p"],
  "include_base64": true
}
```

## Safe prompt template

```text
Review curve quality for my current selection.
Use review_curve_quality for the explicit path, then enable the native overlay with set_curve_review_overlay(enabled=true).
Tell me to inspect View > Show Glyphs MCP Curvature and verify the last draw with get_curve_review_overlay_state.
Do not mutate or save the font.
Report only measurements, conservative warnings, and suggested next checks.
```
