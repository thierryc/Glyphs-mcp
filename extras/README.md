# Optional development material

`glyphs-macro-iteration/` preserves the separately developed Scripting Window workflow and its qualification reference. It is not one of the eleven managed skills in the signed 2.0.4 distribution. Keeping it here prevents an optional workflow from changing the release skill inventory or digest.

To use it, install the folder alongside `glyphs-mcp-scripting` and `glyphs-mcp-development` in your own skill directory. Its qualification covers the print-only macro described in the reference, not a server or font-edit release gate. Existing installed skill links are not changed by repository cleanup.
