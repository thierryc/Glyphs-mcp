# Glyphs MCP 2.2.0 — local test candidate

Prepared on 15 October 2026; updated on 17 October 2026.
Source target: **2.2.0/build 64**, stable channel.
The published stable release and signed feeds remain **2.1.0/build 63**.
A signed and notarized local test candidate is prepared from commit
`48824823`. The earlier unsigned companion remains installed for UI review;
the signed candidate has not replaced the live installation. This record does
not claim publication or a complete upgrade of the running bridge and sidecar.

## Changes

- Keep the sidebar palette title compact as “Glyphs MCP Bridge”, removing its
  explicit version suffix to fix the duplicated version reported in
  [#62](https://github.com/thierryc/Glyphs-mcp/issues/62). Version details remain
  in server settings. This 17 October source follow-up is not included in the
  signed 16 October candidate described below; its native UI remains to be verified.
- Add Tasks to the companion sidebar, app menu, menu-bar controls and Dock.
  Show open workflows, blockers and recently closed tasks in a full-height list;
  remove Recent Tasks from Setup. An unread counter reflects unviewed entries.
- Preserve the existing native design, pill buttons, subtle inactive selection
  and focused accent highlight. Show selectable monospaced Review / Close task
  prompts with a compact copy control.
- Open a recorded Codex conversation when a reliable association is available.
  Claude Code and missing/ambiguous links retain an explained copy-prompt route.
  Ordinary workflow decisions stay in the agent.
- Offer guarded Recovery Options when an agent conversation is unavailable.
  Explain the consequences and distinguish sheet dismissal from task
  cancellation. Reuse authoritative server guards, revisions, tokens and
  existing recovery actions; no new Save/Restore shortcut is added.
- Archive only eligible orphaned interrupted tasks, retain diagnostics and
  record an explicit Unverified outcome. Unknown or active ownership blocks
  archival.
- Clear closed history with a reversible grace period. Eligible cleared
  summaries expire after 30 days from server receipt. Open tasks, recovery,
  diagnostics and Unverified outcomes remain protected. Canonical job and
  workflow records are not deleted.
- Keep the retention explanation in the Clear Closed History confirmation
  dialog and remove its repeated footer caption. Operational compatibility and
  synchronization notices remain visible.
- Add passive `list_tasks` discovery for agents, sharing the companion's
  workflow/job inventory and blocker projection. Reads never execute scripts,
  save fonts, resolve tasks or issue action tokens.
- Preview PNG, JPEG and WebP changes in every project's diff viewer with native
  Before / Both / After controls, a draggable divider and matching zoom/Fit
  controls. Handle transparency, EXIF orientation, differing dimensions and
  missing versions explicitly. Bound input size, decoded pixels, previews and
  cache usage; preserve source files and the Git index.
- Document native sidebar predicate contexts and retained bounded verification.
- Open Projects in Diff by default, filling the workspace below a compact
  header. Config contains font sources, project settings and external-tool
  actions. Switching preserves the current diff, filter and controls. Constrain
  the resizable file list to the available project area to prevent sidebar
  overlap.
- Offer Create Package Copy for saved `.glyphs` sources, independently of Git
  status. Use the bundled CLI with plugins disabled, sibling staging, native
  verification and an atomic no-overwrite publication. Preserve originals and
  disclose possible omission of per-glyph modification timestamps.

synchronization and candidate identity/payload checks. Logs, candidate metadata

standalone native switching, divider drag, accessible slider adjustment, zoom,

63** companion containing those source changes opened a real JPEG and the

removed. This does not cover every version 4 feature. Focused package/layout

that review was verified against its local build receipt; it does not qualify
