## Published stable release

Glyphs MCP **2.0.1/build 56** uses seventeen tools, eleven managed skills, lean
interface revision 1 and bridge protocol 1. The universal app, payload, ZIP and
DMG are Developer ID-signed, Apple-notarized and stapled. Public archive hashes
are verified before the signed stable updater feed is advanced.

## 2.0.2 candidate

The local 2.0.2/build 57 source adds an eighteenth tool, `compare_fonts`, shared
background initialization and optional managed tool setup. See
[candidate build notes](../contributor/release-build-notes.mdx#202-candidate). Source and fixture checks do not
establish signed distribution, installed runtime or native startup acceptance.
Follow-up qualification on macOS 26.7.1 arm64 measured 0.44–0.50-second initial
presentation, including deliberately delayed discovery. Signed/notarized optional
Diffenator and Beztrace packages passed bounded local acceptance, including offline
comparisons and fresh-panel tracing. This evidence does not qualify the exact
signed 2.0.2 desktop distribution. Diffenator downloads and the updated Beztrace
companion remain gated on hosted assets and supported-platform acceptance.

## Accepted 2.0.1 evidence

Qualification passed **2,684 Python tests** (two optional skips), **246 desktop
tests**, deterministic payloads, managed skill synchronization, documentation
and both private runtime architectures. x86_64 startup used Rosetta.

On **macOS 14.6.1 arm64**, **Glyphs 4.1.1/build 4108** and official **Glyphs Python
3.14.6**, the exact signed app passed 2.0.0/build 55 → 2.0.1/build 56 desktop
replacement and rejected invalid feed signatures, invalid archive signatures
and interrupted downloads. Bundled component migration completed successfully.
Automated transaction tests cover replacement failure and rollback recovery.

The running bridge and sidecar hashes matched the installed receipt. Disposable
native fixtures passed Open/retry/reuse, activation, native package Save/Close,
TTF/OTF/UFO imports with source preservation, active-job Close guards,
asynchronous discard recovery and unsaved-close handling. QA documents were
closed at completion. Desktop skill checks cover catalog navigation, GitHub
import, installation, export and removal with preserved backups.

## Earlier 2.0.0 evidence

The release source passed **2,573 Python tests and 233 desktop tests**, package,
skill, documentation, deterministic payload and private-runtime checks.
Both runtime architectures passed startup; x86_64 used Rosetta.

Native signed build 55 testing on **macOS 14.6.1/23G93 arm64**, **Glyphs 4.1.1/build
4108 trial** and official **Glyphs Python 3.14.6** passed fresh MCP install,
Welcome/Setup Ready, loaded identities, width apply/discard/save, real signed
Beta 11/build 53 → stable55 desktop replacement and invalid-feed/archive/interrupted-
download rejection. Component54 → 55 migration, failed migration/automatic rollback,
retry, reboot/loaded checks and signed v1.11.0 migration also passed.

Actual Claude Desktop 2.19675.0 read calls passed against signed build 55. Earlier
conversation and native workflow evidence retains its original build scope;
configuration checks alone do not establish every client's live behavior.

## Limits

- Packaging declares **macOS 14.0+**. Exact 14.0 and current-macOS native acceptance
  remain unverified; 14.6.1 execution does not prove those environments.
- Physical Intel execution is deferred. Universal binaries and Rosetta startup
  do not establish an Intel hardware result.
- Codex and Claude Code live smoke remains unperformed; Cursor VM testing was
  waived based on the maintainer's reported host success.
- Full VoiceOver, visual Reduce Motion timing, linguistic review and a new-user
  documentation walkthrough remain unverified. Technical localization checks
  and bounded native layouts are separate evidence.
- Glyphs 3 preservation used a labelled fixture; live Glyphs 3 coexistence remains
  unverified. Keep its separate [v1 distribution](/docs/).
- Beztrace 0.1.1 engine and the independently signed/notarized Glyphs plugin
  0.1.0/build 15 have separate installation and qualification. Install All does
  not install that plugin.

Keep does not save. Typed recovery checks for conflicting edits. Whole-font
Restore replaces later unsaved edits; save persists the whole current font.
Begin with disposable work and inspect results before using the release on
production fonts.
