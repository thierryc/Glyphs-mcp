# Glyphs MCP 2.8.1 / build 94

Stable release for Glyphs 4. [Download the notarized installer](https://github.com/thierryc/Glyphs-mcp/releases/download/v2.8.1/Glyphs-MCP-2.8.1.dmg)

## What changed

- Update a skill directly from its card. When several installations have updates, choose which agent or project copies to update. Details shows the installation locations and the command for each supported agent.
- Refresh Tasks with ⌘R. The list keeps the last successful result when a request fails and shows when it was updated. Long histories load one page at a time.
- Tasks shows why a request needs attention. Inactive workflows can move to History after the sidecar verifies that work and recovery have ended. Unknown outcomes and possible partial changes remain visible.
- Closed tasks leave History automatically after 30 days. The sidecar retains the underlying job receipts, diagnostics and recovery evidence.

## Compatibility

Glyphs 4 uses desktop build 94 and the coordinated 2.8.1 bridge, sidecar and agent packages. The bridge protocol and lean interface remain at revision 1. Glyphs 3 continues to use the separate 1.11.0 release.
