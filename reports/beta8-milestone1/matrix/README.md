# Native capacity benchmark matrix

Five fresh processes per row; values are median [minimum–maximum]. Seconds unless marked MiB.

The native route includes local workflow preparation, execution, cleanup and polling. The direct route measures callbacks only, with setup and cleanup excluded. Neither includes CLI startup, fixture loading or installed-client latency. Each process loads the same prebuilt fixture. Peak RSS includes that load and the runtime. Dirty cases use the standalone native font writer; actual editor saves are qualified separately.
