# Font project brief example

1. Ask for missing audience, scripts/languages, styles, intended uses and delivery
   requirements. Reuse information already provided by the user.
2. Draft a brief containing those requirements, open questions and success
   criteria. Label assumptions instead of inventing facts.
3. Present the brief for review. Save it only when the user requests a file.

This instruction-only example requires no MCP connection and makes no font edits.
See [example prompts and results](references/examples.md).
