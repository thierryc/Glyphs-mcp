# Glyphs MCP 2.3.1 patch preparation

Source candidate: **2.3.1/build 69**, stable channel, prepared 26 October 2026.
This patch builds on the 2.3.0/build 68 source baseline. Existing published
2.3.0 assets, signed tags and update feeds remain intact.

## Changes

- Present the Glyphs MCP development skill positively in the Codex and Claude
  Code connection cards, with its availability in Skills.
- Add **Include Glyphs MCP development skills** to Connections. It starts
  unchecked, remembers the choice, and includes script/plugin development and
  release skills when setting up Codex or Claude Code.
- Preserve existing development and release skills without marking successful
  connection setup as failed. Opting out leaves their copies and ownership
  receipts intact. Conflicts in other managed font-workflow skills retain their
  existing protection and reporting.
- Translate the new interface copy into English, French and Simplified Chinese.

## Identity

Desktop, bridge, sidecar and four host plugin manifests target **2.3.1**.
The installer build is **69**. The payload still contains eleven skills;
the checkbox controls which skills Setup installs for Codex and Claude Code.
The 22-tool catalog, interface revision 1, bridge protocol 1, pinned Glyphs 3
release and independent companion versions are unchanged.

Planned tag: `v2.3.1`. Planned archives: `Glyphs-MCP-2.3.1.dmg` and
`Glyphs-MCP-2.3.1.zip`. These names describe a source candidate and do not
establish signed artifacts or public availability.

release was published. This patch is carried forward onto published 2.3.0.
