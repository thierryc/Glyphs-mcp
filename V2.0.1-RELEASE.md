# Glyphs MCP Desktop 2.0.1

Desktop build 56 adds a skills catalog and focused setup pages for Glyphs 4.
The catalog now includes seventeen tools with Open, Import, Activate and Close;
eleven bundled skills, interface revision 1 and bridge protocol 1 remain.

## What changes

- Open an existing `.glyphs` file or `.glyphspackage` folder directly through
  MCP. Reuse already-open fonts without reloading unsaved edits; retained keys
  prevent duplicate openings after lost responses. Opening never saves.
- Close the exact font with explicit Save/Discard handling. Pending jobs block
  closing; verified saving completes first and retained retries preserve newer edits.
- Show the exact font window and bring Glyphs to the front.
- Import UFO, OTF or TTF through Glyphs. Preserve the original source and use a
  new native Save As destination; compiled imports report possible data loss.
- Open **Companion Plugins**, **AI Agents** or **Skills** directly below Setup.
  Setup retains the overview and Install All; every page shares installation
  operations, progress and errors.
- Browse compact skill cards with short workflow goals, search, client filters
  and installation badges. Details contain instructions, source, requirements,
  installed copies and lifecycle actions.
- Add public GitHub skills at an immutable revision. Install personally or in
  a selected project: Codex and Cursor share `.agents/skills`, while Claude Code
  uses `.claude/skills`. Optional skills remain outside Install All.
- Update and remove owned copies explicitly. Edited or unowned folders are
  preserved, replacements create verified backups outside discovery, and
  interrupted operations retain recoverable receipts and journals.
- Export complete skill folders as ZIPs for guided ChatGPT and Claude uploads.
  Exporting instructions does not establish access to Glyphs on the Mac.
- Contribute through the public
  [skills repository](https://github.com/thierryc/glyphs-mcp-skills), with a starter
  folder, schema, issue forms and validation that never runs contributor scripts.

The app ships an offline catalog and retains its last valid cache when refresh
fails. Bundled skills retain their existing setup-managed locations. Installation
does not execute skill scripts, install dependencies, change MCP connections or
restart clients. Labels are localized in English, French and Simplified Chinese.

## Validation and distribution

Qualification on October 8, 2026 passed 2,684 Python tests (two optional cases
skipped) and 246 macOS installer tests. Deterministic payloads, catalog validation,
skill synchronization, all seventeen tools and eleven bundled skills pass.
Both private runtime architectures pass HTTP/stdio startup and package checks.
Automated transaction tests cover failed replacement, verification and rollback
recovery; they are distinct from the successful native VM component migration.

The final universal app, compatibility ZIP, versioned/latest DMGs and Sparkle
update archive passed Developer ID signing, Apple notarization, stapling and
Gatekeeper. The app verifies 94 Mach-O files and 47 code bundles. The exact
signed payload passed arm64 and x86_64 runtime startup without package downloads.

On an Apple Silicon VM running macOS 14.6.1, Glyphs 4.1.1/build 4108 and Glyphs
Python 3.14.6, the exact signed desktop upgraded 2.0.0/build 55 to 2.0.1/build 56.
Invalid feed signatures, invalid archive signatures and interrupted downloads
were rejected. The original feed preference was restored after the isolated trial.
The updated manager then successfully migrated its bundled components.

Native checks verified seventeen tools and running bridge/sidecar hashes against
the installed receipt. Disposable fixtures passed Open retry/reuse, activation,
native package Save As and idempotent Close; TTF, OTF and UFO import retries,
native Save As and original source preservation; prepared/applied job Close
guards; asynchronous discard recovery; and default refusal to close a kept
unsaved edit followed by explicit Discard. The test resumed from its journal
after an early Save correctly returned document_busy during asynchronous
recovery. All QA documents were closed at completion. No host font was modified.

Native desktop checks also cover navigation, project preservation, skill
card/details presentation, public GitHub import, project installation into both
client roots, export and removal with verified backups. Catalog license labels
were corrected through merged contribution-repository PR #1.

Physical Intel hardware, the exact macOS 14.0 minimum, human accessibility review,
and hosted ChatGPT/Claude upload-and-invocation acceptance remain unverified.
The x86_64 runtime checks use translation on Apple Silicon. These limits do not
constitute passing native/platform or hosted-client evidence.

Release publication verifies the signed tag, exact main commit and remote tag,
reruns all local gates, and verifies uploaded archive hashes before promoting the
release. The exact signed stable appcast is advanced only after public archive
verification. Glyphs 3 remains pinned to 1.11.0.

Gist import, private GitHub authentication, automatic optional-skill updates and
marketplace publication are deferred.
