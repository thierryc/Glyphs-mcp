# 2.6.0 / build 76 preparation

This record describes the Glyphs Health and Workload Protection preparation
before publication. See the [2.6.0 release qualification](V2.6.0-RELEASE.md) for signed build results.

## Implementation

- Shared bounded health contract; native resource observer; passive cached status.
- Soft font budget, critical-pressure/delayed-dispatch admission and queue waits.
- Automatic structured/text agent feedback and shared skill guidance.
- Companion health details, native menu summary and shared setting (English/French).
- No new public tool, runtime dependency or helper executable.

Architecture, configuration and compatibility: [Glyphs Health](docs/glyphs-health.md).

## Qualification gates

Record exact results in `reports/health-2.6.0/qualification.md` as checks finish.
Passing source tests does not establish loaded native behaviour.

- Focused health, queue, document lifecycle, bridge and sidecar regression tests.
- Complete Python suite, native desktop tests and documentation build.
- Managed skill synchronization, package isolation and deterministic payloads.
- Verified local desktop candidate and independent component identities.
- Cached status p95 below 100 ms with native dispatch blocked.
- Ten-minute isolated observer CPU below 0.5% of one core; bounded one-hour soak.
- Loaded Apple Silicon Glyphs qualification: zero/multiple/large/unsaved fonts,
  long script, retained recovery, multiple clients and companion closed.
- Native job duration within 5% of the matching baseline; controlled pressure
  injection, recovery hysteresis and source preservation.
- Clean installation and 2.5.1 upgrade; signed/notarized artifact verification.
- Intel execution qualification or an explicit retained limitation.

Native safety/performance failures block promotion. Signing/notarization and
publication are separate from an unsigned source/build check. Publication,
tagging, pushing and feed changes are not part of this implementation task.
