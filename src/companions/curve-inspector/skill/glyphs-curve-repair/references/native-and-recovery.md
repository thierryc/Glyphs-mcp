# Native methods and coverage

`GSSUPERSMOOTH` is exact connection state, not `smooth=True`. A star's stored
coordinates can remain fixed while its rendered join moves. The shared adapter
measures native drawing cubics and refuses unsupported correspondence,
undefined curvature, excess deviation and neighbor regressions.

SuperTool is pinned at `ccc71ee39ef72c0c34267410d2b9ebee454ec98c` with Apache-2.0
and Google LLC notices. The Python adaptation adds finite guards and an explicit
oriented tangent-bisector alignment for broken G1. It separates harmonization
from optional balancing; the full upstream command balances before and after.
Balancing alone does not establish G2. No SCGlyphsLib or RMX code is included.

Native evaluation uses detached complete fonts. Multiple axes and contributing
master/intermediate layers are evaluated with a five-position lattice and
independent interleaved locations. Count locations before trials; above 4096,
request an explicit narrower axis region. Finite native locations provide
sampled evidence; continuous bounds concern each evaluated effective outline.
Line/curve raindrops add native effective cubic segments. They use a certified
chord-subdivision correspondence bound, not the corresponding-cubic integral.
The requested join is checked for G2 in the unrounded native construction;
generated joins are checked for G1, with drawing-grid diagnostics kept separate.

Compatible conditional families are evaluated by native interpolation, including
boundary/adjacent locations; the helper does not implement substitution itself.
Manually weighted/variable instances and unclassified special-layer rules remain
unqualified. Components, hint-bearing layers, stroke expansion, topology
conversion of stored paths, zero-handle extraction and G3 are unsupported.
Native line/curve and curve/line transitions are supported when their complete
generated outline can be mapped and certified. Short/reversed lines, omitted
native segments and unqualified expansion patterns are refused. Explicit handle
repair remains curve/curve only.
Do not substitute raw source curves for missing effective native outlines.

The controller provides a native glyph Undo group and independently checked
exception compensation for its own edits. A V2 script still follows V2's
whole-font saved-baseline restoration contract; disabled script Undo cannot be
represented as the controller's recovery. No helper saves or closes a font.

Examples: a preview uses `operation=propose`; an authorized selected repair uses
`operation=repair` with explicit joins; handle repair adds
`method=supertool-handles`; balancing additionally sets `tunniBalance=true`.
Refusal or incomplete coverage is a result to explain, not a reason to increase
tolerance or narrow scope automatically.


Human panel 0.5.0 uses the same bundled geometry engine through bounded direct
actions: Star / Default node, Max change in font units, All masters and Apply.
Default node materializes detached native repair and enables Tunni internally,
with validated native fallback. These human settings do not change the explicit
agent `NativeAdapter` proposal schemas or preview-only authorization. Grid
quantization can require a nonzero visible-outline budget when resolving stars.
