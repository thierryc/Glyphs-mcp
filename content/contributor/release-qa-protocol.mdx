# Release QA protocol

The installer intentionally ships two tracks:

- Glyphs 3.5 -> pinned v1.11 from signed `v1.11.0` / `13ca805`.
- Glyphs 4 -> v2.0 from the deterministic generated bundle.

Catalog equality is not an acceptance criterion across those hosts. Each host
must match its own runtime, safety contract, and payload manifest.

## Automated prerequisite

From repository root:

```bash
python3 scripts/bump_version.py --dry-run --installer-build 27 2.0.0
PYTHON_BIN=python3.12 ./scripts/run_local_release_tests.sh
python3.12 -m pytest -q src/glyphs-mcp/tests/test_v2_*.py
python3.12 scripts/build_v2_knowledge.py --check
python3.12 scripts/render_v2_command_reference.py --check
scripts/sync_codex_plugin_skills.sh --check
```

The consolidated gate verifies exact dependencies including `fontmake`,
schema-v6 classification, deterministic payloads, Knowledge freshness,
generated documentation, authored/packaged skill equality, Python tests, Xcode
tests, and unsigned candidate metadata. Network-backed upstream drift checks
run only when explicitly enabled. The gate does not sign, notarize, install,
tag, upload, or publish.

## Containment

- Use only a disposable Glyphs 4 copy whose family name starts with
  `Glyphs MCP V2 Disposable`. Never open or save a production source.
- Record package tree hash, source fingerprint, canonical fingerprint, native
  archive fingerprint, working path, dirty state, and active master before
  each mutation gate.
- A Glyphs 3.5 check is read-only and must not mutate a document.
- Every Glyphs 4 gate must restore its exact canonical and native baseline,
  path, dirty state, and active master.
- No live installation is replaced. Installer tests use simulated roots.
- Treat a development symlink and its generated target as one effective live
  installation. Stop rather than qualifying a `dev` build as a release.

## Glyphs 3.5 pinned-runtime matrix

| ID | Action | Required result |
| --- | --- | --- |
| G3-1 | Launch with the pinned link. | Runtime is exactly v1.11; no v2 module loads. |
| G3-2 | Start, stop, restart, and reconnect. | No duplicate server or stale event loop. |
| G3-3 | Run server info, open-font listing, and a bounded read. | V1.11 result; document and source bytes unchanged. |
| G3-4 | Inspect update state. | The pin prevents a v2 replacement. |

Do not run v2 mutations, staged Python, or history gates on Glyphs 3.5.

## Glyphs 4 generic v2 matrix

Record Glyphs build, Python version, bundle hash, server version, catalog size,
discovery payload size, and disposable `documentId`.

### Runtime, reads, and constraints

| ID | Action | Required result |
| --- | --- | --- |
| G4-1 | Start, stop, restart, and reconnect. | API major 2 and exactly 18 public tools. |
| G4-2 | Inspect discovery and generated docs. | Catalog, typed handlers, and command reference agree; retired workflow names are absent. |
| G4-3 | Exercise paginated selectors, relations, canonical fields, and computed observations across all entity kinds. | Cursors are bound to selector, projection, schema, and fingerprint; provenance/completeness are explicit; reads do not mutate. |
| G4-4 | Exercise literal, field, and exact-reference constraints before and after a detached candidate. | The same evaluator supplies standalone, preview, and read-back evidence. |
| G4-5 | Call `get_runtime_status`; repair only if it reports a manager-owned incident. | `repair_runtime` is idempotent, status is re-read once, and no loop occurs. |

### Generic mutation and Python gates

Run each existing disposable gate independently:

| ID | Gate | Required result |
| --- | --- | --- |
| G4-6 | `verify_generic_change_lifecycle` | Exact generic insert/set/move/duplicate/remove preview, apply, history, stale refusal, conflict-aware revert, and baseline restoration. |
| G4-7 | `verify_generic_kerning_lifecycle` | Exact stored kerning read/write/revert with unrelated domains preserved. |
| G4-8 | `verify_staged_python_preview_lifecycle` | Detached code runs once, returns a generic immutable preview, applies through `apply_change`, verifies, reverts, and never reruns code. |
| G4-9 | `verify_open_document_view` | Exact glyph view opens without document mutation or save. |
| G4-10 | `verify_copy_and_make_copy` | Detached native copy evidence preserves the source and does not become a working-font save path. |

Add manual `execute_python` cases for unsupported API inspection, staged code
that produces no changes, runtime error, stale preview, verification failure,
and one explicitly approved `live_open_world` temporary-file effect. The live
case must distinguish verified document effects from unverifiable external
effects and report its checkpoint/recovery evidence. Remove the temporary file
after evidence is recorded.

Every successful document apply and revert reports one transaction, operation
ID, audit receipt, and history entry. Stale dependencies, partial application,
read-back mismatch, or rollback failure must fail atomically.

### Persistence and export

| ID | Action | Required result |
| --- | --- | --- |
| G4-11 | `save_document` Save As to a new absolute temporary destination. | Confirmed fingerprint-bound response reports `saveMode=save_as`; original bytes remain unchanged and no reversible history commit is created. |
| G4-12 | Run `preview_export`, then `apply_export` for its exact immutable preview. | Destination and runtime drift are refused; deterministic regeneration and atomic publication match the preview. |
| G4-13 | Reuse a consumed or stale change/export preview. | Refused without replaying planning, Python, or external publication. |

Run G4-11 with `overwritePolicy=fail_if_exists`. After recording its evidence,
close the Save As document without further saving, remove the temporary
destination, reopen the original disposable source, and prove clean baseline
restoration.

### Typographic proof

Tool qualification proves mechanics, not design quality. Use focused skills to
proof spacing, kerning, interpolation, Unicode, OpenType, variable/color
sources, and export artifacts. Record source, binary, shaping, and visual
evidence separately. A stored-value read-back alone is not typographic proof.

## Simulated installer matrix

Use temporary Glyphs Application Support roots only.

| ID | Action | Required result |
| --- | --- | --- |
| I-1 | Build the payload twice. | Complete file maps are byte-identical. |
| I-2 | Inspect `payload.json`. | Glyphs 3 maps to pinned 1.11 and Glyphs 4 maps to 2.0. |
| I-3 | Install/reinstall each target independently. | The other target remains byte-identical. |
| I-4 | Inject replacement failure. | Prior target bundle restores; other target is untouched. |
| I-5 | Uninstall either target. | Other runtimes, skills, documents, and unrelated preferences remain. |
| I-6 | Start from development symlinks. | They remain unless replacement was explicitly selected. |

## Qualification record

Record only evidence actually run:

```md
- Candidate and installer build:
- Branch and commit:
- Automated tests and skips:
- Knowledge/docs/skills generation checks:
- Payload SHA-256 values:
- Glyphs 3.5 build / Python / runtime / result:
- Glyphs 4 build / Python / runtime / result:
- Generic gate results:
- Baseline canonical/native/source restoration:
- Open blockers or accepted limitations:
- Signing: not performed
- Notarization: not performed
- Publication: not performed
```

Passing this protocol produces an unsigned local candidate. Commit, merge,
signed tag, signing, notarization, draft creation, upload, and publication
remain separate authorized actions.
