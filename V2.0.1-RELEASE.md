# Glyphs MCP Desktop 2.0.1

Desktop build 56 adds a skills catalog and focused setup pages for Glyphs 4.
The catalog now includes seventeen tools with Open, Import, Activate and Close;
eleven bundled skills, interface revision 1 and bridge protocol 1 remain.

## What changes

- Open an existing `.glyphs` file or `.glyphspackage` folder directly through
  MCP. Reuse already-open fonts without reloading unsaved edits; retained keys
  prevent duplicate openings after lost responses. Opening never saves.
- Close the exact font with explicit Save/Discard handling. Pending jobs block
  closing; verified saving completes first and retained retries preserve newer edits.
- Show the exact font window and bring Glyphs to the front.
- Import UFO, OTF or TTF through Glyphs. Preserve the original source and use a
  new native Save As destination; compiled imports report possible data loss.
- Open **Companion Plugins**, **AI Agents** or **Skills** directly below Setup.
  Setup retains the overview and Install All; every page shares installation
  operations, progress and errors.
- Browse compact skill cards with short workflow goals, search, client filters
  and installation badges. Details contain instructions, source, requirements,
  installed copies and lifecycle actions.
- Add public GitHub skills at an immutable revision. Install personally or in
  a selected project: Codex and Cursor share `.agents/skills`, while Claude Code
  uses `.claude/skills`. Optional skills remain outside Install All.
- Update and remove owned copies explicitly. Edited or unowned folders are
  preserved, replacements create verified backups outside discovery, and
  interrupted operations retain recoverable receipts and journals.
- Export complete skill folders as ZIPs for guided ChatGPT and Claude uploads.
  Exporting instructions does not establish access to Glyphs on the Mac.
- Contribute through the public
  [skills repository](https://github.com/thierryc/glyphs-mcp-skills), with a starter
  folder, schema, issue forms and validation that never runs contributor scripts.

The app ships an offline catalog and retains its last valid cache when refresh
fails. Bundled skills retain their existing setup-managed locations. Installation
does not execute skill scripts, install dependencies, change MCP connections or
restart clients. Labels are localized in English, French and Simplified Chinese.

synchronization pass, and package checks verify all seventeen tools and eleven
bundled skills. Native desktop checks cover navigation, project preservation,
card/details presentation, public GitHub import, project installation into both
client roots, export and removal with verified backups.
