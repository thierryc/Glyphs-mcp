# Specialized requests in the current lean build

Reuse the verified connection and intended document ID. Do not repeat discovery
or load coding resources until the requested work needs them.

Color-font, variable-font, icon/Unicode, production/export and LitSquare audit
families from the retired private typed interface are not included in the current
lean payload. Their old `apiMajor == 2` gate does not prove that a current lean
runtime needs updating. State which requested evidence is unavailable through
the seven tools; never claim that a partial read completes a full audit.

- “Audit this icon font”: use the metadata reference for explicitly named glyphs
  if that answers the requested check. A full encoding-stability audit needs a
  separately scoped native or offline task; it is not an advertised MCP audit.
- “Review a variable or color font”: explain the missing source/export/visual
  evidence before proposing native inspection or existing-binary analysis. Do
  not invoke retired tools or use another job to simulate an unsupported audit.
- “Write a Glyphs 4 audit script”: use the development/scripting skill and its
  pinned documentation for the agreed scope. A native script is separate from
  the MCP's seven tools. Writing it needs no document discovery; executing it
  must use the intended live font and verify its results.
- A separate v1 connection uses its available v1 skills after catalog and identity
  verification. It does not inherit the lean connection's document IDs or jobs.

If an installed obsolete skill remains selectable, report its exact path. The
installer preserves unowned/user-edited conflicts. Its **Replace preserved skills
(backup)** action archives recognized retired private families outside discovery,
with exact copies and restoration coordinates. It preserves v1 instructions.
Archiving does not implement the retired capability. Plugin caches and source
worktrees are separate: do not edit them as an installation shortcut. A task
that already loaded old instructions may need a new skill-discovery session;
verify the selected file rather than assuming hot refresh.
