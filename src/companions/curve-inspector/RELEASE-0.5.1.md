# Curve Inspector 0.5.1 — Inspect & Repair

Packaging and distribution patch over 0.5.0. The bundle build is 8; the repair
engine remains 0.5.0 with identical implementation bytes. The fixed 280 × 146
point Star / Default node panel, automatic scope, effective-outline limit,
All masters, internal Tunni fallback and per-glyph Undo are unchanged.

This release adds the project Apache license to the plugin and bundled skill.
The plugin uses a Developer ID signature, secure timestamp, hardened runtime,
accepted Apple notarization and a stapled ticket. Local publication preparation
keeps Glyphs MCP desktop/server versions and update feeds unchanged.

Existing 0.5.0 native evidence covers both repair modes, selected handles,
line/curve transitions, limits, adjacent joins, master rejection and Undo on
Glyphs 4.1.1 build 4108. This patch requires focused packaging/trust and loaded
version checks; it does not claim new interpolation, export or platform coverage.
Expanded raindrop-to-regular conversion, expanded corner/cap/brush and stroke
coverage remain unsupported. The separate agent skill is bundled and retains
its explicit preview-only and native script recovery rules.

Local signed/notarized preparation is in progress. Final installation and sealed
asset evidence are recorded in `qualification/release-0.5.1.json` when complete.
GitHub publication and public download verification remain unperformed.
