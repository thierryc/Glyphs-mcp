# Glyphs MCP 2.1.0 — build 63

Product and release version: **2.1.0**. Installer build: **63**. Stable-channel release preparation, authorized for publication on 15 October 2026. Publication and exact distribution verification are recorded separately from the earlier local acceptance below.

The previous public baseline is **2.0.4/build 61**. Its tag, artifacts and historical qualification are preserved. The prepared 2.1.0 distribution does not inherit signing, notarization or native acceptance from that release.

## Changes

- Use the new complete app icon in client integration assets.
- Browse each project template before creation with a folder tree, selectable file text and inline image previews. Project previews render the chosen name and connection values from the same snapshot used for creation.
- Present eleven bundled skills and four existing optional workflows with readable “Glyphs …” titles while retaining stable invocation identifiers.
- Synchronize skill/catalog metadata, explain respacing routes and correct stale prompt and pre-run snapshot-recovery guidance.
- Preserve development links and local optional work; refresh installed skill copies with backups and retire recognized obsolete global entries.
- Prepare optional skill-source packaging improvements without claiming new published download pins or native qualification.
- Move historical planning documents into [the history area](docs/history/) and organize [the qualification index](reports/README.md), retaining evidence and source checkouts.
- Use grouped native questions for unresolved decisions and missing information, with ordinary chat as fallback. Native conversation feedback handles routine progress, success and errors; cards remain optional for useful visual evidence, inspection, reports, live controls or recovery.
- Add read-only `show_edit_workflow` to open a card explicitly. Starting, reading and responding to workflows no longer attach UI resources automatically. Native answers retain existing action-token, revision and authorization checks.
- Reuse clicked buttons for short working/completion labels and a slower final fade, without changing their size or adding duplicate buttons. Use consistent icon spacing, an in-button countdown, a compact pause icon and a discreet countdown line below the actions.
- Disable Automatic Keep before waiting on native questions. Silence, Skip and dismissal do not select a choice or end recovery. Timed Keep remains limited to eligible visible, connected, reconciled successful cards.
- Align tutorials, references, packaged skills and documentation checks with the [conversation UI guide](docs/conversation-ui-directives.md). Rich visual inspection still requires a suitable renderer or native Glyphs view; the lifecycle card is not a dedicated outline viewer.

- Present Keep, Save and Restore in that order, with Save emphasized and script Restore in the main action row. Preserve typed Undo and legacy restoration semantics, pathless Save As, failed-result choices, Automatic Keep and checkpoint warnings.
- Show action consequences beneath the controls with bold action names. Accessible descriptions remain available without hover tooltips. Confirmed completion text persists after button feedback fades; uncertain outcomes never receive success text.

## Contracts retained

Twenty data/action tools plus one optional read-only card-display tool, eleven managed skills, interface revision 1 and bridge protocol 1. Existing locked runtime dependencies and independent companion versions remain unchanged. Glyphs 3 retains its separate pinned 1.11.0 release.
